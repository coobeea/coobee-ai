> **任务 ID**: Task-3  
> **优先级**: P0  
> **依赖**: Task-1（ChannelPlugin 接口定义）  
> **预计工期**: 0.3 天

## 1. 需求描述

### 1.1 用户需求

**背景**：

- 当前 ExtensionApi 支持注册工具、钩子、Gateway 方法
- 已有 `registerChannel()` 方法，但只支持简单的 `ChannelConfig`
- 需要扩展 API，支持注册完整的 `ChannelPlugin`

**核心需求**：

1. 新增 `registerChannelPlugin()` 方法
2. 保留原有 `registerChannel()` 方法（向后兼容）
3. 支持 Channel 验证（ID 重复检查、必填字段检查）
4. 自动注册到 ChannelManager

**期望效果**：

- Extension 可以注册完整的 ChannelPlugin
- 系统自动管理 Channel 生命周期
- 类型安全，IDE 自动补全

---

### 1.2 技术约束

1. **向后兼容**：
   - 保留现有 `registerChannel(ChannelConfig)` 方法
   - 新增 `registerChannelPlugin(ChannelPlugin)` 方法
   - 两者可以共存

2. **类型安全**：
   - 参数必须是完整的 `ChannelPlugin` 类型
   - 支持 TypeScript 类型推断

3. **职责单一**：
   - ExtensionApi 只负责注册
   - 实际管理逻辑在 ChannelManager 中

---

## 2. 解决方案

### 2.1 设计思路

**扩展策略**：增量扩展，不破坏现有功能

```
ExtensionApi (现有)
├── registerTool()
├── registerGatewayMethod()
├── registerChannel()       ← 保留（向后兼容）
└── registerChannelPlugin() ← 新增（本任务）
```

**调用流程**：

```
Extension.register(api)
       ↓
api.registerChannelPlugin(plugin)
       ↓
ExtensionManager.channelPlugins.push(plugin)
       ↓
ChannelManager.registerChannelPlugin(plugin)
```

### 3.2 ExtensionManager 扩展

```typescript
// src/main/common/extension/ExtensionManager.ts

import type { ChannelPlugin } from '@main/channels/types';
import { ChannelManager } from '@main/channels/ChannelManager';

export class ExtensionManager {
  // 存储所有注册的 ChannelPlugin
  private channelPlugins: Map<string, ChannelPlugin> = new Map();

  /**
   * 创建 ExtensionApi（扩展 registerChannelPlugin 方法）
   */
  private createApi(manifest: ExtensionManifest): ExtensionApi {
    return {
      // 现有方法...

      registerChannelPlugin: (plugin: ChannelPlugin) => {
        this.logger.info(`[ExtensionManager] Registering ChannelPlugin: ${plugin.id} from ${manifest.id}`);

        // 1. 验证 Plugin
        this.validateChannelPlugin(plugin);

        // 2. 检查重复
        if (this.channelPlugins.has(plugin.id)) {
          throw new Error(`ChannelPlugin "${plugin.id}" is already registered by another extension`);
        }

        // 3. 存储到本地
        this.channelPlugins.set(plugin.id, plugin);

        // 4. 注册到 ChannelManager
        const channelManager = ChannelManager.getInstance();
        channelManager.registerChannelPlugin(plugin);

        this.logger.info(`[ExtensionManager] ChannelPlugin "${plugin.id}" registered successfully`);
      }
    };
  }

  /**
   * 验证 ChannelPlugin
   */
  private validateChannelPlugin(plugin: ChannelPlugin): void {
    // 1. 检查必填字段
    if (!plugin.id || typeof plugin.id !== 'string') {
      throw new Error('ChannelPlugin.id is required and must be a string');
    }

    if (!plugin.name || typeof plugin.name !== 'string') {
      throw new Error('ChannelPlugin.name is required and must be a string');
    }

    // 2. 检查 lifecycle
    if (!plugin.lifecycle) {
      throw new Error(`ChannelPlugin "${plugin.id}" must have lifecycle hooks`);
    }

    if (typeof plugin.lifecycle.start !== 'function') {
      throw new Error(`ChannelPlugin "${plugin.id}" must implement lifecycle.start()`);
    }

    if (typeof plugin.lifecycle.stop !== 'function') {
      throw new Error(`ChannelPlugin "${plugin.id}" must implement lifecycle.stop()`);
    }

    // 3. 检查 ID 格式
    if (!/^[a-z0-9-]+$/.test(plugin.id)) {
      throw new Error(`ChannelPlugin ID "${plugin.id}" is invalid. Use lowercase letters, numbers, and hyphens only.`);
    }
  }

  /**
   * 获取所有注册的 ChannelPlugin
   */
  public getChannelPlugins(): ChannelPlugin[] {
    return Array.from(this.channelPlugins.values());
  }

  /**
   * 根据 ID 获取 ChannelPlugin
   */
  public getChannelPlugin(id: string): ChannelPlugin | undefined {
    return this.channelPlugins.get(id);
  }
}
```

### 3.3 ChannelManager 扩展

```typescript
// src/main/channels/ChannelManager.ts

import type { ChannelPlugin } from './types';

export class ChannelManager {
  private channels: Map<string, ManagedChannel> = new Map();
  private channelPlugins: Map<string, ChannelPlugin> = new Map(); // ← 新增

  /**
   * 注册 ChannelPlugin（新增）
   */
  public registerChannelPlugin(plugin: ChannelPlugin): void {
    if (this.channelPlugins.has(plugin.id)) {
      this.logger.warn(`ChannelPlugin "${plugin.id}" is already registered. Overwriting.`);
    }

    // 存储 Plugin
    this.channelPlugins.set(plugin.id, plugin);

    // 转换为 ManagedChannel
    this.channels.set(plugin.id, {
      config: {
        id: plugin.id,
        name: plugin.name,
        gateway: {
          start: plugin.lifecycle.start,
          stop: plugin.lifecycle.stop
        }
      },
      status: 'stopped',
      plugin // ← 保存 Plugin 引用
    });

    this.logger.info(`Registered ChannelPlugin: ${plugin.id} (${plugin.name})`);
  }

  /**
   * 获取 ChannelPlugin
   */
  public getChannelPlugin(id: string): ChannelPlugin | undefined {
    return this.channelPlugins.get(id);
  }

  /**
   * 列出所有 ChannelPlugin
   */
  public listChannelPlugins(): ChannelPlugin[] {
    return Array.from(this.channelPlugins.values());
  }
}
```

### 3.5 使用示例

#### 示例 1: 注册 Discussion Channel

```typescript
// extensions/discussion-channel/index.ts

import type { ExtensionModule } from '@main/common/extension';
import type { ChannelPlugin } from '@main/channels/types';

const discussionChannel: ChannelPlugin = {
  id: 'discussion',
  name: 'Discussion Room',
  description: 'Multi-agent discussion room',

  lifecycle: {
    start: async (ctx) => {
      ctx.log.info('[DiscussionChannel] Started');
    },
    stop: async (ctx) => {
      ctx.log.info('[DiscussionChannel] Stopped');
    }
  },

  inbound: {
    handleMessage: async (msg) => {
      // 处理入站消息
    }
  },

  outbound: {
    sendMessage: async (msg) => {
      // 发送出站消息
    }
  },

  capabilities: {
    supportsMultiAgent: true
  }
};

export default {
  id: 'discussion-channel',
  name: 'Discussion Channel Extension',

  register: (api) => {
    // ✅ 使用新 API 注册
    api.registerChannelPlugin(discussionChannel);
  }
} as ExtensionModule;
```
