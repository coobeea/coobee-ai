> **任务 ID**: Task-4  
> **优先级**: P1

---

## 1. 需求描述

### 1.1 用户需求

**背景**：

- 现有 ChannelManager 只支持简单的 `ChannelConfig`
- 需要支持完整的 `ChannelPlugin`（包含 inbound/outbound/capabilities）
- 需要提供 Plugin 查询接口（供 Gateway 和 Frontend 使用）

**核心需求**：

1. 支持存储和管理 `ChannelPlugin`
2. 提供查询接口（getChannelPlugin、listChannelPlugins）
3. 保留向后兼容性（现有 registerChannel 仍可用）
4. 支持 Channel 能力查询（capabilities）

**期望效果**：

- ChannelManager 成为 ChannelPlugin 的唯一管理者
- 前端可以查询 Channel 能力（决定 UI 显示）
- Gateway 可以查询 Plugin（调用 inbound/outbound）

---

### 1.2 技术约束

1. **向后兼容**：
   - 保留现有 `ManagedChannel` 结构
   - 扩展字段，不删除现有字段

2. **单例模式**：
   - ChannelManager 必须是单例
   - 全局唯一实例

3. **线程安全**：
   - 支持并发注册（多个 Extension 同时注册）
   - 使用 Map 存储（JavaScript 单线程，无需锁）

---

## 2. 解决方案

### 2.1 设计思路

**扩展策略**：在现有 ChannelManager 基础上增量扩展

```
ChannelManager (现有)
├── channels: Map<string, ManagedChannel>  ← 保留
├── registerChannel(config)                ← 保留
├── startChannel(id)                       ← 保留
├── stopChannel(id)                        ← 保留
└── getStatus()                            ← 保留

ChannelManager (扩展)
├── channelPlugins: Map<string, ChannelPlugin>  ← 新增
├── registerChannelPlugin(plugin)               ← 新增
├── getChannelPlugin(id)                        ← 新增
├── listChannelPlugins()                        ← 新增
└── getChannelCapabilities(id)                  ← 新增
```

## 3. 详细设计

### 3.1 ChannelManager 扩展

```typescript
// src/main/channels/ChannelManager.ts

import type { ChannelPlugin } from './types';

export class ChannelManager {
  private static instance: ChannelManager;
  private channels: Map<string, ManagedChannel> = new Map();
  private channelPlugins: Map<string, ChannelPlugin> = new Map(); // ← 新增
  private logger: ExtensionLogger = log;

  private constructor() {}

  public static getInstance(): ChannelManager {
    if (!ChannelManager.instance) {
      ChannelManager.instance = new ChannelManager();
    }
    return ChannelManager.instance;
  }

  // ==================== 新增方法 ====================

  /**
   * 注册 ChannelPlugin
   *
   * @param plugin - ChannelPlugin 实例
   */
  public registerChannelPlugin(plugin: ChannelPlugin): void {
    if (this.channelPlugins.has(plugin.id)) {
      this.logger.warn(`ChannelPlugin "${plugin.id}" is already registered. Overwriting.`);
    }

    // 1. 存储 Plugin
    this.channelPlugins.set(plugin.id, plugin);

    // 2. 转换为 ManagedChannel
    this.channels.set(plugin.id, {
      config: {
        id: plugin.id,
        name: plugin.name,
        gateway: {
          start: plugin.lifecycle.start,
          stop: plugin.lifecycle.stop
        }
      },
      status: 'stopped',
      plugin // ← 保存 Plugin 引用
    });

    this.logger.info(`Registered ChannelPlugin: ${plugin.id} (${plugin.name})`);
  }

  /**
   * 根据 ID 获取 ChannelPlugin
   *
   * @param id - Channel ID
   * @returns ChannelPlugin 或 undefined
   */
  public getChannelPlugin(id: string): ChannelPlugin | undefined {
    return this.channelPlugins.get(id);
  }

  /**
   * 列出所有 ChannelPlugin
   *
   * @returns ChannelPlugin 数组
   */
  public listChannelPlugins(): ChannelPlugin[] {
    return Array.from(this.channelPlugins.values());
  }

  /**
   * 获取 Channel 能力声明
   *
   * @param id - Channel ID
   * @returns ChannelCapabilities 或 undefined
   */
  public getChannelCapabilities(id: string): ChannelCapabilities | undefined {
    const plugin = this.channelPlugins.get(id);
    return plugin?.capabilities;
  }

  /**
   * 检查 Channel 是否支持指定能力
   *
   * @param id - Channel ID
   * @param capability - 能力名称
   * @returns boolean
   */
  public supportsCapability(id: string, capability: keyof ChannelCapabilities): boolean {
    const capabilities = this.getChannelCapabilities(id);
    return capabilities?.[capability] === true;
  }

  // ==================== 现有方法（保留） ====================

  /**
   * 注册通道（旧方法，保留向后兼容）
   */
  public registerChannel(config: ChannelConfig): void {
    if (this.channels.has(config.id)) {
      this.logger.warn(`Channel "${config.id}" is already registered. Overwriting.`);
    }
    this.channels.set(config.id, {
      config,
      status: 'stopped'
    });
    this.logger.info(`Registered channel: ${config.id} (${config.name})`);
  }

  // ... 其他现有方法保持不变
}
```

### 3.4 Gateway HTTP 接口

新增 Gateway 路由供前端查询：

```typescript
// src/main/gateway/http/channels.ts（新文件）

import type { Context } from 'koa';
import Router from '@koa/router';
import { ChannelManager } from '@main/channels/ChannelManager';

export function registerChannelRoutes(router: Router): void {
  const manager = ChannelManager.getInstance();

  /**
   * 列出所有 Channel
   * GET /gateway/channels
   */
  router.get('/channels', (ctx: Context) => {
    const plugins = manager.listChannelPlugins();
    ctx.body = plugins.map((p) => ({
      id: p.id,
      name: p.name,
      description: p.description,
      capabilities: p.capabilities
    }));
  });

  /**
   * 获取单个 Channel 详情
   * GET /gateway/channels/:id
   */
  router.get('/channels/:id', (ctx: Context) => {
    const plugin = manager.getChannelPlugin(ctx.params.id);
    if (!plugin) {
      ctx.status = 404;
      ctx.body = { error: 'Channel not found' };
      return;
    }
    ctx.body = {
      id: plugin.id,
      name: plugin.name,
      description: plugin.description,
      capabilities: plugin.capabilities
    };
  });

  /**
   * 获取 Channel 能力
   * GET /gateway/channels/:id/capabilities
   */
  router.get('/channels/:id/capabilities', (ctx: Context) => {
    const capabilities = manager.getChannelCapabilities(ctx.params.id);
    ctx.body = capabilities || {};
  });
}
```

import { describe, it, expect, beforeEach } from 'vitest';
