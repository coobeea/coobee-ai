# 16.5 - Discussion Channel 迁移

> **任务 ID**: Task-5  
> **优先级**: P1  
> **依赖**: Task-2（ChannelRuntime）, Task-3（ExtensionApi 扩展）  
> **预计工期**: 0.5 天

---

## 1. 需求描述

### 1.1 用户需求

**背景**：

- 当前讨论室功能分散在多个地方：
  - `src/main/ai/discussion/DiscussionRoom.ts` - 核心逻辑
  - `src/main/ai/discussion/DiscussionStore.ts` - 数据存储
  - `src/main/gateway/http/discussion.ts` - HTTP 路由
- 讨论室未作为 Channel 实现，无法复用 ChannelRuntime
- Agent 调用逻辑需要重复编写

**核心需求**：

1. 将讨论室改造为 ChannelPlugin
2. 使用 ChannelRuntime 调度 Agent
3. 保持现有 API 不变（前端无感知）
4. 实现真正的 Agent 轮转（不再是占位文本）

**期望效果**：

- 讨论室成为标准 Channel
- Agent 通过 ChannelRuntime 执行
- 多 Agent 自动轮转
- 前端 UI 无需任何修改

---

### 1.2 技术约束

1. **保持 API 不变**：
   - HTTP 路由路径不变（`/gateway/discussion/*`）
   - 请求/响应格式不变
   - 前端代码无需修改

2. **复用现有数据层**：
   - 继续使用 `DiscussionStore`
   - 继续使用 SQLite 存储
   - 数据库 Schema 不变

3. **渐进式迁移**：
   - 先实现 ChannelPlugin
   - 再重构 DiscussionRoom
   - 最后调整 HTTP 路由

---

## 2. 解决方案

### 2.1 设计思路

**迁移策略**：三步走

```
Step 1: 创建 discussion-channel Extension
       ↓
Step 2: 重构 DiscussionRoom（使用 ChannelRuntime）
       ↓
Step 3: 调整 Gateway HTTP 路由（调用 ChannelPlugin）
```

**架构变化**：

```
【旧架构】
Gateway HTTP → DiscussionRoom → agentExecutor（直接调用）
                     ↓
               DiscussionStore

【新架构】
Gateway HTTP → ChannelPlugin.inbound.handleMessage
                     ↓
               ChannelRuntime.executeAgent
                     ↓
               agentExecutor（统一调度）
```

#### 3.1.2 ChannelPlugin 实现

```typescript
// extensions/discussion-channel/DiscussionChannel.ts

import type { ChannelPlugin, InboundMessage, OutboundMessage } from '@main/channels/types';
import { ChannelRuntime } from '@main/channels/ChannelRuntime';
import { DiscussionStore } from '@main/ai/discussion/DiscussionStore';
import { Gateway } from '@main/gateway/Gateway';

let logger: any;

/**
 * Discussion ChannelPlugin
 *
 * 将讨论室作为 Channel 实现，与飞书、Slack 等外部 Channel 平等对待
 */
export const discussionChannel: ChannelPlugin = {
  id: 'discussion',
  name: 'Discussion Room',
  description: 'Multi-agent discussion room for collaborative problem solving',

  lifecycle: {
    /**
     * 启动 Discussion Channel
     */
    start: async (ctx) => {
      logger = ctx.log;
      logger.info('[DiscussionChannel] Started');

      // 初始化 DiscussionStore
      await DiscussionStore.getInstance();
    },

    /**
     * 停止 Discussion Channel
     */
    stop: async (ctx) => {
      logger.info('[DiscussionChannel] Stopped');
    }
  },

  inbound: {
    /**
     * 处理入站消息（讨论室 → Agent）
     *
     * @param msg - 入站消息
     */
    handleMessage: async (msg: InboundMessage) => {
      try {
        const runtime = ChannelRuntime.getInstance();
        const store = await DiscussionStore.getInstance();

        // 1. 获取讨论室信息
        const session = await store.get(msg.peer);
        if (!session) {
          logger.error(`[DiscussionChannel] Session ${msg.peer} not found`);
          return;
        }

        // 2. 找到当前发言的参与者
        const participant = session.participants.find((p) => p.agentId === msg.from);
        if (!participant) {
          logger.error(`[DiscussionChannel] Participant ${msg.from} not found`);
          return;
        }

        // 3. 构建 Channel 上下文
        const context = {
          channel: 'discussion',
          roomId: msg.peer,
          role: participant.roleName,
          topic: session.topic,
          recentMessages: session.messages.slice(-5).map((m) => ({
            sender: m.participant,
            content: m.content
          }))
        };

        // 4. 调用 ChannelRuntime 执行 Agent
        const result = await runtime.executeAgent({
          agentId: msg.from,
          sessionId: `discussion-${msg.peer}-${msg.from}`,
          message: msg.text,
          context
        });

        if (result.error) {
          logger.error(`[DiscussionChannel] Agent execution error: ${result.error}`);
          return;
        }

        // 5. 发送回复到讨论室
        await discussionChannel.outbound!.sendMessage({
          to: msg.peer,
          agentId: msg.from,
          text: result.output
        });
      } catch (err) {
        logger.error('[DiscussionChannel] Error handling message:', err);
      }
    }
  },

  outbound: {
    /**
     * 发送出站消息（Agent → 讨论室）
     *
     * @param msg - 出站消息
     */
    sendMessage: async (msg: OutboundMessage) => {
      try {
        const store = await DiscussionStore.getInstance();

        // 1. 保存消息到数据库
        await store.addMessage(msg.to, {
          participant: msg.agentId,
          content: msg.text,
          timestamp: Date.now()
        });

        logger.info(`[DiscussionChannel] Message sent to room ${msg.to} from ${msg.agentId}`);

        // 2. 广播到前端
        const gateway = Gateway.getInstance();
        gateway.broadcast(`discussion:${msg.to}`, {
          type: 'message',
          data: {
            participant: msg.agentId,
            content: msg.text,
            timestamp: Date.now()
          }
        });
      } catch (err) {
        logger.error('[DiscussionChannel] Error sending message:', err);
      }
    }
  },

  capabilities: {
    supportsMultiAgent: true,
    supportsStreaming: false,
    supportsTools: false,
    supportsMedia: false
  }
};
```

### 3.2 Step 2: 重构 DiscussionRoom

#### 3.2.1 移除直接调用 agentExecutor

**旧代码**：

```typescript
// src/main/ai/discussion/DiscussionRoom.ts (旧版本)

export class DiscussionRoom {
  async start(): Promise<void> {
    // ❌ 直接调用 agentExecutor
    const builder = agentExecutor.piMono();
    builder.name('agent-name').instructions('...');
    // ...
  }
}
```

**新代码**：

```typescript
// src/main/ai/discussion/DiscussionRoom.ts (新版本)

import type { ChannelPlugin } from '@main/channels/types';
import { ChannelManager } from '@main/channels/ChannelManager';

export class DiscussionRoom {
  /**
   * 开始讨论（触发第一个 Agent 发言）
   */
  async start(): Promise<void> {
    // 1. 保存 session 到数据库
    await this.store.save(this.session);

    // 2. 添加系统消息
    await this.store.addMessage(this.session.id, {
      participant: 'System',
      content: `Discussion started. Topic: ${this.session.topic}`,
      timestamp: Date.now()
    });

    // 3. 获取 Discussion Channel Plugin
    const manager = ChannelManager.getInstance();
    const plugin = manager.getChannelPlugin('discussion');

    if (!plugin || !plugin.inbound) {
      throw new Error('Discussion channel not available');
    }

    // 4. 选择第一个发言者
    const firstSpeaker = this.getNextSpeaker();

    // 5. 触发 inbound.handleMessage
    await plugin.inbound.handleMessage({
      peer: this.session.id,
      from: firstSpeaker.agentId,
      text: `You are ${firstSpeaker.roleName}. Please start the discussion on: ${this.session.topic}`,
      context: {
        channel: 'discussion',
        roomId: this.session.id,
        role: firstSpeaker.roleName,
        topic: this.session.topic,
        recentMessages: []
      }
    });
  }

  /**
   * 下一轮（自动轮转）
   */
  async nextTurn(): Promise<void> {
    const nextSpeaker = this.getNextSpeaker();

    const manager = ChannelManager.getInstance();
    const plugin = manager.getChannelPlugin('discussion');

    if (!plugin || !plugin.inbound) {
      throw new Error('Discussion channel not available');
    }

    await plugin.inbound.handleMessage({
      peer: this.session.id,
      from: nextSpeaker.agentId,
      text: `Continue the discussion. Recent messages: ${this.getRecentSummary()}`,
      context: {
        channel: 'discussion',
        roomId: this.session.id,
        role: nextSpeaker.roleName,
        topic: this.session.topic,
        recentMessages: this.session.messages.slice(-5).map((m) => ({
          sender: m.participant,
          content: m.content
        }))
      }
    });
  }
}
```

### 3.3 Step 3: 调整 Gateway HTTP 路由

```typescript
// src/main/gateway/http/discussion.ts

import { ChannelManager } from '@main/channels/ChannelManager';

/**
 * 开始讨论
 * POST /gateway/discussion/sessions/:id/start
 */
router.post('/discussion/sessions/:id/start', async (ctx: Context) => {
  try {
    const { id } = ctx.params;

    // 1. 加载讨论室
    const store = await DiscussionStore.getInstance();
    const session = await store.get(id);

    if (!session) {
      ctx.status = 404;
      ctx.body = { error: 'Discussion session not found' };
      return;
    }

    // 2. 创建 DiscussionRoom 实例
    const room = new DiscussionRoom(session, store);

    // 3. 开始讨论（内部调用 ChannelPlugin）
    await room.start();

    // 4. 启动自动轮转（每个 Agent 发言后自动触发下一个）
    // 注意：这里可以通过监听消息事件自动触发

    ctx.body = { success: true };
  } catch (err) {
    ctx.status = 500;
    ctx.body = { error: err instanceof Error ? err.message : 'Internal server error' };
  }
});
```

### 3.4 自动轮转机制

#### 方案 1: 事件驱动（推荐）

```typescript
// extensions/discussion-channel/DiscussionChannel.ts

outbound: {
  sendMessage: async (msg: OutboundMessage) => {
    // 1. 保存消息
    await store.addMessage(msg.to, { ... });

    // 2. 广播到前端
    gateway.broadcast(`discussion:${msg.to}`, { ... });

    // 3. 检查是否需要自动轮转
    const session = await store.get(msg.to);
    if (session.status === 'active' && session.turnStrategy === 'round-robin') {
      // 延迟 2 秒后自动触发下一个 Agent
      setTimeout(async () => {
        const room = new DiscussionRoom(session, store);
        await room.nextTurn();
      }, 2000);
    }
  }
}
```

#### 方案 2: 手动控制

```typescript
// Gateway HTTP 路由

/**
 * 下一轮
 * POST /gateway/discussion/sessions/:id/next-turn
 */
router.post('/discussion/sessions/:id/next-turn', async (ctx: Context) => {
  const { id } = ctx.params;

  const store = await DiscussionStore.getInstance();
  const session = await store.get(id);

  const room = new DiscussionRoom(session, store);
  await room.nextTurn();

  ctx.body = { success: true };
});
```

### 3.5 数据流图

```
前端 UI
  ↓ POST /gateway/discussion/sessions/:id/start
Gateway HTTP 路由
  ↓ new DiscussionRoom(session)
  ↓ room.start()
DiscussionRoom
  ↓ plugin.inbound.handleMessage({ from: agent1, ... })
ChannelPlugin.inbound
  ↓ runtime.executeAgent({ agentId: agent1, ... })
ChannelRuntime
  ↓ agentExecutor.stream({ sessionId, message, builder })
AgentExecutor
  ↓ LLM API 调用
  ↓ 返回 output
ChannelRuntime
  ↓ return { output }
ChannelPlugin.outbound
  ↓ sendMessage({ to: roomId, text: output })
  ↓ store.addMessage()
  ↓ gateway.broadcast()
前端 UI（收到 WebSocket 事件）
  ↓ 显示新消息
  ↓ 自动触发 nextTurn()
```
