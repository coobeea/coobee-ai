# 16.1 - ChannelPlugin 接口定义

> **任务 ID**: Task-1  
> **优先级**: P0  
> **依赖**: 无  
> **预计工期**: 0.5 天

---

## 1. 需求描述

### 1.1 用户需求

**背景**：

- 当前系统中，讨论室、专家会诊等功能直接调用 `agentExecutor`，每个功能都要重复实现相同的逻辑
- 未来需要对接飞书、Slack、Discord 等外部系统，但缺乏统一的抽象层
- 需要一个标准接口，让所有"通信渠道"用同样的方式与 Agent 交互

**核心需求**：

1. 定义统一的 Channel 抽象接口
2. 规范 Channel 的生命周期管理（启动/停止）
3. 定义标准的消息格式（入站/出站）
4. 支持 Channel 能力声明（流式输出、工具可视化等）

**期望效果**：

- 新增一个 Channel 只需实现标准接口
- 所有 Channel 用同样的方式与 Agent 通信
- Channel 与 Agent 完全解耦

---

### 1.2 技术约束

1. **兼容现有架构**：
   - 不破坏现有的 `ChannelManager`
   - 不影响现有的 Extension 系统
   - 类型定义必须与 `ExtensionApi` 兼容

2. **TypeScript 类型安全**：
   - 所有接口必须有完整的类型定义
   - 避免使用 `any` 和 `unknown`
   - 支持泛型扩展

3. **参考业界标准**：
   - 对标 OpenClaw 的 ChannelPlugin 设计
   - 保留核心 Adapter，去除冗余部分
   - 简化 API，降低接入成本

---

## 2. 解决方案

### 2.1 设计思路

**核心理念**：将 Channel 视为"消息转换器"

```
外部世界        Channel           Agent
  消息    →    Inbound Adapter  →  Agent 执行
  ↓            ↓                   ↓
飞书群聊     parseMessage()      executeAgent()
  ↑            ↑                   ↑
  响应    ←    Outbound Adapter ←  Agent 输出
```

**设计分层**：

1. **消息格式层**：定义 `InboundMessage` / `OutboundMessage`
2. **Channel 接口层**：定义 `ChannelPlugin` 标准接口
3. **生命周期层**：定义 `start` / `stop` 钩子
4. **能力声明层**：定义 `capabilities` 字段

---

### 2.2 接口概览

```typescript
// 核心接口关系
ChannelPlugin {
  id: string
  name: string
  lifecycle: { start, stop }
  inbound?: { handleMessage }
  outbound?: { sendMessage }
  capabilities?: { ... }
}

InboundMessage {  // Channel → Agent
  peer: string
  from: string
  text: string
  context: ChannelContext
}

OutboundMessage {  // Agent → Channel
  to: string
  text: string
  agentId: string
}
```

## 3. 详细设计

### 3.1 类型定义

#### 3.1.1 Channel 上下文

```typescript
/**
 * Channel 上下文
 *
 * 传递给 Agent 的额外信息，每个 Channel 可以自由扩展
 */
export interface ChannelContext {
  /** Channel ID */
  channel: string;
  /** Channel 特定字段（灵活扩展） */
  [key: string]: unknown;
}
```

**设计要点**：

- 使用索引签名 `[key: string]: unknown` 允许任意扩展
- `channel` 字段必填，用于标识消息来源
- 示例：

  ```typescript
  // Discussion Channel
  context: {
    channel: 'discussion',
    roomId: 'room-123',
    role: 'Expert',
    topic: 'AI Architecture'
  }

  // Feishu Channel
  context: {
    channel: 'feishu',
    chatId: 'oc_xxx',
    chatType: 'group',
    messageId: 'om_yyy'
  }
  ```

---

#### 3.1.2 入站消息格式

```typescript
/**
 * 入站消息（Channel → Agent）
 *
 * 所有 Channel 发送给 Agent 的消息必须转换为此格式
 */
export interface InboundMessage {
  /** 对话标识（讨论室 ID / 飞书 chatId / Slack channelId） */
  peer: string;

  /** 发送者标识（参与者 ID / 用户 openId / Slack userId） */
  from: string;

  /** 消息文本内容 */
  text: string;

  /** Channel 上下文 */
  context: ChannelContext;

  /** 媒体附件（可选） */
  media?: MediaAttachment[];

  /** 消息元数据（可选） */
  metadata?: Record<string, unknown>;
}

/** 媒体附件 */
export interface MediaAttachment {
  /** 类型：image/video/audio/file */
  type: 'image' | 'video' | 'audio' | 'file';
  /** 资源 URL 或本地路径 */
  url: string;
  /** 文件名（可选） */
  name?: string;
  /** 文件大小（字节，可选） */
  size?: number;
}
```

**设计要点**：

- `peer` 用于 Session 隔离（同一 peer 共享历史）
- `from` 用于标识发送者（多 Agent 场景区分身份）
- `text` 是核心内容，必填
- `media` 支持多媒体消息（飞书图片、Slack 文件等）
- `metadata` 预留扩展字段

---

#### 3.1.3 出站消息格式

```typescript
/**
 * 出站消息（Agent → Channel）
 *
 * Agent 生成的回复消息，由 Channel 发送到目标平台
 */
export interface OutboundMessage {
  /** 目标标识（讨论室 ID / 飞书 chatId / Slack channelId） */
  to: string;

  /** 消息文本内容 */
  text: string;

  /** 发送者 Agent ID */
  agentId: string;

  /** 附件（可选） */
  attachments?: MediaAttachment[];

  /** 回复目标消息 ID（可选，用于 reply-to） */
  replyTo?: string;

  /** 消息元数据（可选） */
  metadata?: Record<string, unknown>;
}
```

**设计要点**：

- `to` 与入站消息的 `peer` 对应
- `agentId` 标识回复的 Agent（多 Agent 场景）
- `replyTo` 支持消息引用（飞书话题、Slack threads）

---

#### 3.1.4 Channel 生命周期上下文

```typescript
/**
 * Channel 生命周期上下文
 *
 * 传递给 start/stop 钩子的参数
 */
export interface ChannelLifecycleContext {
  /** 绑定的 AbortSignal（用于安全退出） */
  abortSignal: AbortSignal;

  /** 日志接口 */
  log: ExtensionLogger;

  /** Channel 配置（可选） */
  config?: Record<string, unknown>;
}
```

**设计要点**：

- `abortSignal` 用于优雅停止（Gateway 关闭时触发）
- `log` 统一日志接口
- `config` 支持 Channel 特定配置（如飞书 appId、Slack token）

#### 3.1.5 ChannelPlugin 核心接口

```typescript
/**
 * ChannelPlugin 接口
 *
 * 所有 Channel 必须实现此接口
 */
export interface ChannelPlugin {
  /** Channel 唯一 ID（如 'discussion', 'feishu', 'slack'） */
  id: string;

  /** Channel 显示名称 */
  name: string;

  /** 描述（可选） */
  description?: string;

  /** 生命周期钩子 */
  lifecycle: {
    /**
     * 启动 Channel 监听
     *
     * 此方法应：
     * 1. 初始化连接（WebSocket、HTTP Server 等）
     * 2. 注册事件监听器
     * 3. 返回 Promise（当 abortSignal 触发时 resolve）
     */
    start: (ctx: ChannelLifecycleContext) => Promise<void> | void;

    /**
     * 停止 Channel 监听
     *
     * 此方法应：
     * 1. 清理连接
     * 2. 注销事件监听器
     * 3. 释放资源
     */
    stop: (ctx: ChannelLifecycleContext) => Promise<void> | void;
  };

  /**
   * 入站消息处理器（可选）
   *
   * Channel 收到消息后，调用 handleMessage 转发给 Agent
   */
  inbound?: {
    handleMessage: (msg: InboundMessage) => Promise<void>;
  };

  /**
   * 出站消息发送器（可选）
   *
   * Agent 回复后，调用 sendMessage 发送到 Channel
   */
  outbound?: {
    sendMessage: (msg: OutboundMessage) => Promise<void>;
  };

  /**
   * 能力声明（可选）
   */
  capabilities?: ChannelCapabilities;
}
```

#### 3.1.6 能力声明

```typescript
/**
 * Channel 能力声明
 *
 * 用于声明 Channel 支持的特性
 */
export interface ChannelCapabilities {
  /** 支持多 Agent 协作 */
  supportsMultiAgent?: boolean;

  /** 支持流式输出 */
  supportsStreaming?: boolean;

  /** 支持工具调用可视化 */
  supportsTools?: boolean;

  /** 支持媒体消息 */
  supportsMedia?: boolean;

  /** 支持消息编辑 */
  supportsEdit?: boolean;

  /** 支持消息删除 */
  supportsDelete?: boolean;

  /** 支持 Reactions（表情回应） */
  supportsReactions?: boolean;
}
```

**设计要点**：

- 所有字段可选，默认 `false`
- 前端 UI 可根据能力声明调整显示（如隐藏不支持的功能按钮）
- 未来可扩展更多能力（如投票、富文本、卡片等）

### 3.3 使用示例

#### 示例 1: Discussion Channel

```typescript
// extensions/discussion-channel/index.ts

const discussionChannel: ChannelPlugin = {
  id: 'discussion',
  name: 'Discussion Room',

  lifecycle: {
    start: async (ctx) => {
      ctx.log.info('[DiscussionChannel] Started');
    },
    stop: async (ctx) => {
      ctx.log.info('[DiscussionChannel] Stopped');
    }
  },

  inbound: {
    handleMessage: async (msg: InboundMessage) => {
      // 调用 ChannelRuntime 执行 Agent
      const runtime = ChannelRuntime.getInstance();
      const result = await runtime.executeAgent({
        agentId: msg.from,
        sessionId: `discussion-${msg.peer}-${msg.from}`,
        message: msg.text,
        context: msg.context
      });

      // 发送回复
      await this.outbound!.sendMessage({
        to: msg.peer,
        agentId: msg.from,
        text: result.output
      });
    }
  },

  outbound: {
    sendMessage: async (msg: OutboundMessage) => {
      // 保存到数据库 + 广播到前端
    }
  },

  capabilities: {
    supportsMultiAgent: true,
    supportsStreaming: false,
    supportsTools: false
  }
};
```
