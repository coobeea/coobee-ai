## 🗂️ 维护指南

### 文档命名规范

未来新增文档时，建议遵循以下规范：

1. **文件名格式**: `主题-简短描述.md`
   - 示例：`exec-tool-fix-report.md`
   - 使用小写字母和连字符

2. **状态标签**: 在文档开头添加状态标签

   ```markdown
   > **状态**: ✅ 已实现 / 🔧 进行中 / 📋 规划中 / 🔍 调研中
   > **创建时间**: 2026-02-24
   ```

3. **避免重复**:
   - 同一主题只保留一份正式文档
   - 版本迭代在原文件中更新，而非新建文件
   - 临时笔记应在完成后整合到正式文档或删除

### 定期清理

建议每 6 个月清理一次归档目录：

- 删除已过时且无参考价值的文档
- 合并高度重叠的文档
- 更新文档状态标签
