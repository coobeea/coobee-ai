## 🏗️ 架构特性

### Agent-first 架构

```
用户界面 (Vue)
    ↓
HTTP API (Express)
    ↓
TrainingExecutor (策略模式)
    ├─ Sequential (串行)
    ├─ Parallel (并行)
    └─ Adaptive (自适应)
    ↓
AgentDelegator (重试/超时)
    ↓
ChannelRuntime.executeAgent()
    ↓
├─ training-evaluator    (评估输出质量)
├─ training-coach        (生成改进建议)
└─ training-data-generator (生成训练任务)
```
