**预计耗时**：10 轮 × ~10 秒/轮 = **约 1.5 分钟**

---

### Step 5: 查看结果和分析

训练完成后：

1. **查看训练曲线**
   - 观察得分是否上升

2. **查看维度雷达图**
   - 识别强项和弱项维度

3. **点击"弱点分析"**
   - 查看失败率最高的维度
   - 查看改进建议

4. **创建训练后的版本**
   - 点击"创建版本"
   - 输入版本描述（如"完成基础代码生成训练"）
   - 版本会保存在 `agents/app-copilot/versions/` 目录

## 🎓 进阶使用

### 并行训练（提速 3-5 倍）

创建新训练会话时：

- **训练策略**：选择 `parallel`
- **并行度**：建议 3-5
- **训练轮次**：可以设置 50-100 轮

**优点**：速度快，适合大规模训练  
**缺点**：资源消耗高，API 调用频繁

---

### 自适应训练（智能优化）

创建新训练会话时：

- **训练策略**：选择 `adaptive`
- **训练轮次**：100 轮以上

**特点**：

- 自动调整任务难度
- 针对弱点维度强化训练
- 根据表现动态优化

---

### 增量训练（弱点强化）

适用场景：已完成一轮训练，发现某些维度较弱

步骤：

1. 打开已完成的训练会话详情页
2. 点击"弱点分析"
3. 查看弱点维度和改进建议
4. 点击"继续训练"（自动针对弱点生成新任务）
5. 配置增量训练轮次（如 50 轮）
6. 开始训练

## 📊 数据集和目标管理

### 数据集结构

```json
{
  "name": "数据集名称",
  "version": "1.0.0",
  "category": "分类",
  "trainSet": [
    {
      "id": "任务唯一ID",
      "description": "任务描述",
      "difficulty": 1-5,
      "category": "分类"
    }
  ],
  "testSet": [
    {
      "id": "测试任务ID",
      "description": "测试任务描述",
      "difficulty": 1-5,
      "category": "分类"
    }
  ]
}
```

**推荐配比**：

- 训练集：测试集 = 3:1 或 4:1
- 难度分布：简单 30% / 中等 50% / 困难 20%

---

### 训练目标结构

```json
{
  "name": "目标名称",
  "description": "目标描述",
  "dimensions": [
    {
      "name": "维度名称",
      "description": "维度说明",
      "weight": 0.25,
      "criteria": ["标准1", "标准2"]
    }
  ],
  "threshold": 75
}
```

**推荐设置**：

- 维度数量：3-5 个
- 权重总和：1.0
- 及格阈值：70-80 分

## 🔍 常见问题

### Q1: 训练很慢怎么办？

**解决方案**：

1. 使用并行训练策略
2. 减少训练轮次
3. 使用更快的 AI 模型（如 deepseek-chat）
4. 减小数据集规模

### Q2: 训练得分不提升？

**可能原因**：

1. 数据集质量问题（任务描述不清晰）
2. 训练目标过于严格（降低 threshold）
3. Agent 本身能力限制
4. 训练轮次不足（建议至少 100 轮）

**解决方案**：

1. 检查数据集任务描述是否明确
2. 降低及格阈值到 60-70 分
3. 增加训练轮次到 100-500 轮
4. 使用自适应策略

### Q3: 如何验证训练效果？

**方法**：

1. 查看测试集得分（TestSetValidator）
2. 对比训练前后的版本
3. 在实际任务中使用训练后的 Agent
4. 观察弱点维度是否改善

### Q4: 训练后的版本如何使用？

**方法 1（手动切换）**：

```bash
# 查看所有版本
ls ~/coobee-data/homes/app-copilot/versions/

# 将训练后的版本覆盖到主定义
cp ~/coobee-data/homes/app-copilot/versions/{version-id}.json \
   ~/git/git_agents/coobee-ai/agents/app-copilot.json
```

**方法 2（通过 UI）**：

- 进入 Agent 管理页
- 选择要使用的版本
- 点击"设为当前版本"

## 🎯 推荐训练流程

### 首次训练（探索基线）

1. **小规模测试**：10 轮，串行策略
2. **观察表现**：查看各维度得分
3. **识别弱点**：运行弱点分析
4. **调整目标**：根据实际表现调整 threshold

### 正式训练（能力提升）

1. **大规模训练**：100-500 轮，并行策略
2. **自适应优化**：使用 adaptive 策略
3. **弱点强化**：针对弱点维度增量训练
4. **测试集验证**：定期检查过拟合

### 持续优化（长期迭代）

1. **定期训练**：每周/每月进行一次训练
2. **数据集更新**：根据实际使用场景补充任务
3. **版本管理**：保留重要版本，便于回滚
4. **效果评估**：在真实任务中验证训练效果

## ⚠️ 注意事项

### 数据安全

- 训练会话文件存储在 `~/coobee-data/training/sessions/`
- 训练版本存储在 `~/coobee-data/homes/{agentId}/versions/`
- 定期备份重要的训练数据和版本

### 资源消耗

- 并行训练会占用更多 CPU/内存
- 大规模训练会产生较多 API 调用（成本）
- 建议在闲时进行大规模训练

### 质量保证

- 定期使用测试集验证（防过拟合）
- 对比训练前后的实际表现
- 保留训练前的版本（便于回滚）

## 🆘 故障排除

### 训练无法启动

1. 检查数据集路径是否正确
2. 检查数据集格式是否符合规范
3. 查看后端日志：`~/coobee-data/logs/training.log`

### 训练中断

1. 查看会话状态：训练列表页
2. 如果状态为"运行中"但实际已停止：点击"停止"
3. 如果需要恢复：点击"恢复"
4. 如果无法恢复：删除会话，重新创建

### UI 显示异常

1. 刷新页面
2. 检查浏览器控制台错误
3. 查看 WebSocket 连接状态
4. 重启应用
