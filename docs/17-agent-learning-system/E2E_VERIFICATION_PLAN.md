# 端到端验证计划

## 📋 验证目标

验证 Agent 训练模式的完整流程，确保所有功能在实际使用中正常工作。

---

## 🎯 验证范围

### 1. 前置准备

- [ ] 准备训练数据集（JSON 格式）
- [ ] 确认至少有一个可训练的 Agent
- [ ] 启动应用进入开发模式

### 2. 基础训练流程

#### 2.1 创建训练会话

- [ ] 点击"智能体训练"进入训练列表页
- [ ] 点击"创建训练"按钮
- [ ] 选择智能体（如 `app-copilot`）
- [ ] 选择训练目标（如"代码生成能力"）
- [ ] 配置训练轮次（建议先测试 10 轮）
- [ ] 选择训练策略（先测试"串行"）
- [ ] 点击"开始训练"

#### 2.2 监控训练进度

- [ ] 验证跳转到训练详情页
- [ ] 验证实时进度更新
- [ ] 验证训练曲线实时绘制
- [ ] 验证状态显示正确（运行中）

#### 2.3 训练控制

- [ ] 测试"暂停"功能
- [ ] 验证状态变为"已暂停"
- [ ] 测试"恢复"功能
- [ ] 验证状态变为"运行中"
- [ ] 测试"停止"功能
- [ ] 验证状态变为"已完成"

#### 2.4 结果分析

- [ ] 查看训练进度曲线
- [ ] 查看维度雷达图
- [ ] 点击"弱点分析"
- [ ] 验证弱点维度识别
- [ ] 查看改进建议

#### 2.5 版本管理

- [ ] 点击"创建版本"按钮
- [ ] 验证版本创建成功
- [ ] 查看 Agent 版本列表
- [ ] 验证版本信息（训练前后对比）

---

### 3. 高级功能验证

#### 3.1 并行训练

- [ ] 创建新会话，选择"并行"策略
- [ ] 配置并行度为 3
- [ ] 验证训练速度提升
- [ ] 验证结果正确性

#### 3.2 自适应训练

- [ ] 创建新会话，选择"自适应"策略
- [ ] 验证难度自动调整
- [ ] 验证弱点强化
- [ ] 查看难度变化趋势

#### 3.3 增量训练

- [ ] 完成一次训练后查看弱点分析
- [ ] 点击"继续训练"
- [ ] 验证系统针对弱点生成新任务
- [ ] 验证弱点维度得分提升

---

### 4. WebSocket 实时更新

- [ ] 打开训练列表页
- [ ] 在另一个窗口创建新训练
- [ ] 验证列表页实时更新
- [ ] 验证统计数字实时变化

---

### 5. 错误处理

#### 5.1 边界情况

- [ ] 测试无效的 Agent ID
- [ ] 测试无效的数据集路径
- [ ] 测试训练轮次为 0
- [ ] 验证错误提示清晰

#### 5.2 异常恢复

- [ ] 训练中关闭应用
- [ ] 重启应用
- [ ] 验证会话状态正确
- [ ] 验证可以恢复训练

## 🔧 验证工具

### 日志查看

```bash
# 查看训练日志
tail -f ~/coobee-data/logs/training.log

# 查看 Agent 调用日志
tail -f ~/coobee-data/logs/agent.log
```

### 数据检查

```bash
# 查看训练会话文件
ls -lh ~/coobee-data/training/sessions/

# 查看会话详情
cat ~/coobee-data/training/sessions/{session-id}.json | jq
```

### 性能监控

```bash
# 监控 CPU 和内存
top -pid $(pgrep -f "coobee-ai")

# 监控 API 调用次数
grep "executeAgent" ~/coobee-data/logs/agent.log | wc -l
```
