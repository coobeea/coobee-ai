# Coobee 智库（Brain）设计方案

> **创建时间**: 2026-02-23  
> **状态**: 设计阶段  
> **参考**: EvoMap GEP-A2A 协议 + Tavern Integration 架构  
> **命名**: 智库（Brain）- 经验复用与方案积累系统

---

## 1. 核心理念

### 1.1 EvoMap 的优秀设计思想

从 EvoMap 学习到的核心价值：

| 设计思想                 | 说明                                           | 我们是否采纳          |
| ------------------------ | ---------------------------------------------- | --------------------- |
| **三元组知识结构**       | 策略（Gene） + 实现（Capsule） + 过程（Event） | ✅ 采纳（换名）       |
| **内容寻址（SHA256）**   | 内容决定 ID，去重 + 完整性校验                 | ✅ 采纳               |
| **强制完整性（Bundle）** | 必须策略+实现一起发布                          | ✅ 采纳               |
| **生命周期管理**         | candidate → validated → promoted               | ✅ 采纳（简化）       |
| **质量评分体系**         | GDI Score（通用度+可靠性+影响力）              | ⏳ 后续考虑           |
| **收益分享机制**         | Credits + Reputation                           | ❌ 不采纳（内部使用） |
| **全球网络**             | 多节点协作进化                                 | ❌ 不采纳（单机模式） |
| **Envelope Pattern**     | 7 层协议封装                                   | ⚠️ 简化版             |

## 2. 我们的命名体系

### 2.1 核心概念映射

不直接使用 EvoMap 的命名，设计符合中文语境的新名称：

| EvoMap 概念        | 我们的命名   | 英文标识    | 说明                                  |
| ------------------ | ------------ | ----------- | ------------------------------------- |
| **Gene**           | **方案模板** | `Pattern`   | 解决问题的策略/方法论                 |
| **Capsule**        | **实践案例** | `Practice`  | 具体的实现和效果                      |
| **EvolutionEvent** | **演进记录** | `Evolution` | 解决过程和经验                        |
| **Bundle**         | **经验包**   | `Package`   | Pattern + Practice + Evolution 的组合 |
| **Hub**            | **智库**     | `Brain`     | 本地文件系统存储                      |
| **Node**           | **智能体**   | `Agent`     | 使用系统的 Agent                      |

### 2.2 命名理由

#### 方案模板（Pattern）

- **不用 "策略"**：太抽象，不够直观
- **不用 "模板"**：容易和代码模板混淆
- **选择 "方案模板"**：
  - ✅ 明确是"解决方案"
  - ✅ "模板"体现可复用性
  - ✅ 符合中文习惯

#### 实践案例（Practice）

- **不用 "实现"**：太技术化
- **不用 "案例"**：不够突出实践性
- **选择 "实践案例"**：
  - ✅ 强调"实际做过"
  - ✅ "案例"体现参考价值
  - ✅ 与"方案模板"对应

#### 演进记录（Evolution）

- **不用 "过程"**：太平淡
- **不用 "事件"**：容易和系统事件混淆
- **选择 "演进记录"**：
  - ✅ 体现迭代优化
  - ✅ "记录"明确是历史
  - ✅ 与 EvoMap 的"进化"理念一致

#### 经验包（Package）

- **不用 "捆绑包"**：翻译腔太重
- **不用 "知识包"**：太抽象
- **选择 "经验包"**：
  - ✅ 强调实践经验
  - ✅ "包"体现完整性
  - ✅ 与"智库"呼应

## 4. 数据结构设计

### 4.1 方案模板（Pattern）

**对标 EvoMap Gene**

```typescript
interface Pattern {
  type: 'Pattern';
  schema_version: string; // "1.0.0"

  // === 核心信息 ===
  name: string; // 方案名称（唯一）
  summary: string; // 简短描述（最少 10 字）
  description?: string; // 详细说明

  // === 问题识别 ===
  category: 'repair' | 'optimize' | 'innovate'; // 类别
  signals: string[]; // 触发信号（如 "TimeoutError", "内存溢出"）
  contexts: string[]; // 适用场景（如 "API 调用超时时"）
  preconditions?: string[]; // 前提条件

  // === 解决方案 ===
  strategy: string; // 解决策略
  constraints?: Record<string, unknown>; // 约束条件
  expected_outcomes?: string[]; // 预期效果

  // === 验证 ===
  validation?: string[]; // 验证命令

  // === 元数据 ===
  asset_id: string; // SHA256 hash
  created_at: string; // ISO 8601
  author?: string; // 作者（Agent ID）
}
```

**示例**：

```json
{
  "type": "Pattern",
  "schema_version": "1.0.0",
  "name": "http-timeout-retry",
  "summary": "HTTP 超时时使用指数退避重试",
  "category": "repair",
  "signals": ["TimeoutError", "ECONNREFUSED", "ETIMEDOUT"],
  "contexts": ["当 API 调用超时时", "当网络连接不稳定时", "当遇到速率限制时"],
  "strategy": "使用指数退避重试机制：首次重试间隔 1 秒，之后每次翻倍，最多重试 3-5 次",
  "constraints": {
    "max_retries": 5,
    "max_delay_ms": 30000
  },
  "expected_outcomes": ["成功率提升 30% 以上", "自动处理临时网络故障"],
  "validation": ["pnpm test -- retry"],
  "asset_id": "sha256:abc123...",
  "created_at": "2026-02-23T10:00:00Z"
}
```

### 4.2 实践案例（Practice）

**对标 EvoMap Capsule**

```typescript
interface Practice {
  type: 'Practice';
  schema_version: string;

  // === 核心信息 ===
  name: string; // 案例名称
  summary: string; // 简短描述（最少 20 字）
  content: string; // 完整内容（代码、配置、步骤）

  // === 关联 ===
  pattern_id: string; // 关联的方案模板 asset_id
  triggers: string[]; // 触发信号

  // === 效果评估 ===
  confidence: number; // 置信度（0-1）
  success_streak: number; // 连续成功次数
  impact: {
    // 影响范围
    files: number;
    lines: number;
  };
  outcome: {
    // 实际效果
    status: 'success' | 'failure';
    score: number; // 0-1
    metrics?: Record<string, unknown>;
  };

  // === 环境信息 ===
  environment: {
    platform: string; // 'darwin' | 'linux' | 'win32'
    node_version?: string;
    dependencies?: string[];
  };

  // === 元数据 ===
  asset_id: string; // SHA256 hash
  created_at: string;
  author?: string;
}
```

### 4.3 演进记录（Evolution）

**对标 EvoMap EvolutionEvent**

```typescript
interface Evolution {
  type: 'Evolution';
  schema_version: string;

  // === 关联 ===
  practice_id: string; // 关联的实践案例
  patterns_used: string[]; // 使用的方案模板列表

  // === 过程记录 ===
  intent: 'repair' | 'optimize' | 'innovate';
  attempts: Array<{
    // 尝试记录
    approach: string; // 尝试的方法
    result: 'success' | 'failure';
    reason?: string; // 失败原因或成功原因
    metrics?: Record<string, unknown>;
  }>;

  // === 结果 ===
  outcome: {
    status: 'success' | 'failure';
    score: number;
    final_choice: string; // 最终选择
    reason: string; // 为什么选择这个
  };

  // === 统计 ===
  mutations_tried: number; // 尝试次数
  total_duration_ms?: number; // 总耗时

  // === 元数据 ===
  asset_id: string;
  created_at: string;
}
```

## 5. HTTP API 设计

### 5.1 核心端点

参考 Tavern 的 HTTP 集成模式，设计 RESTful API：

```typescript
// === 发布与查询（协议端点）===
POST   /api/brain/publish          // 发布经验包
POST   /api/brain/search           // 搜索经验包
POST   /api/brain/fetch            // 获取完整经验包

// === 管理（RESTful 端点）===
GET    /api/brain/packages         // 列出所有经验包
GET    /api/brain/packages/:id     // 获取单个经验包详情
DELETE /api/brain/packages/:id     // 撤回经验包

GET    /api/brain/patterns         // 列出所有方案模板
GET    /api/brain/practices        // 列出所有实践案例
GET    /api/brain/stats            // 统计信息
```

### 5.2 消息格式

**简化版的 Envelope Pattern**（不需要 EvoMap 的 7 层完整封装）：

```typescript
interface ApiRequest<T = unknown> {
  // === 基础信息（3 个字段，而非 EvoMap 的 7 个）===
  message_id: string; // 消息 ID
  timestamp: string; // ISO 8601
  payload: T; // 业务数据
}

interface ApiResponse<T = unknown> {
  success: boolean;
  data?: T;
  error?: {
    code: string;
    message: string;
  };
  meta?: {
    request_id: string;
    elapsed_ms: number;
  };
}
```

**发布请求示例**：

```json
{
  "message_id": "msg_1708675200_abc123",
  "timestamp": "2026-02-23T10:00:00Z",
  "payload": {
    "pattern": { ... },
    "practice": { ... },
    "evolution": { ... }
  }
}
```

````
## 15. 技术实现要点（Python）

### 15.1 SHA256 计算（asset.py）

参考 EvoMap 的规范：

```python
import hashlib
import json

def compute_asset_id(asset: dict) -> str:
    """计算资产的 SHA256 ID"""
    # 1. 移除 asset_id 字段（如果存在）
    content = {k: v for k, v in asset.items() if k != 'asset_id'}

    # 2. 规范化 JSON（排序 keys）
    canonical = json.dumps(content, sort_keys=True, ensure_ascii=False)

    # 3. 计算 SHA256
    hash_hex = hashlib.sha256(canonical.encode('utf-8')).hexdigest()

    return f"sha256:{hash_hex}"
````

### 15.2 文件系统存储（storage.py）

```python
import os
import json
from pathlib import Path
from typing import Optional

class FileSystemStore:
    def __init__(self, storage_dir: str):
        self.storage_dir = Path(storage_dir)
        self.packages_dir = self.storage_dir / 'packages'
        self.packages_dir.mkdir(parents=True, exist_ok=True)

    def save_package(self, pkg: dict) -> None:
        """保存经验包"""
        pkg_dir = self.packages_dir / pkg['package_id']
        pkg_dir.mkdir(parents=True, exist_ok=True)

        # 写入主文件
        self._write_json(pkg_dir / 'package.json', pkg)
        self._write_json(pkg_dir / 'pattern.json', pkg['pattern'])
        self._write_json(pkg_dir / 'practice.json', pkg['practice'])

        if 'evolution' in pkg and pkg['evolution']:
            self._write_json(pkg_dir / 'evolution.json', pkg['evolution'])

    def load_package(self, package_id: str) -> Optional[dict]:
        """加载经验包"""
        pkg_path = self.packages_dir / package_id / 'package.json'
        if not pkg_path.exists():
            return None

        with open(pkg_path, 'r', encoding='utf-8') as f:
            return json.load(f)

    def _write_json(self, path: Path, data: dict) -> None:
        """写入 JSON 文件"""
        with open(path, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
```

### 15.3 索引管理（indexer.py）

```python
import json
from pathlib import Path
from typing import List, Set

class IndexManager:
    def __init__(self, storage_dir: str):
        self.storage_dir = Path(storage_dir)
        self.index_dir = self.storage_dir / 'index'
        self.index_dir.mkdir(parents=True, exist_ok=True)

    def add_package(self, pkg: dict) -> None:
        """添加经验包到索引"""
        pattern = pkg['pattern']
        package_id = pkg['package_id']
        timestamp = pkg['created_at']

        # 按信号索引
        for signal in pattern['signals']:
            self._append_index('by-signal', {
                'signal': signal,
                'package_id': package_id,
                'timestamp': timestamp
            })

        # 按类别索引
        self._append_index('by-category', {
            'category': pattern['category'],
            'package_id': package_id,
            'timestamp': timestamp
        })

        # 按状态索引
        self._append_index('by-status', {
            'status': pkg['status'],
            'package_id': package_id,
            'timestamp': timestamp
        })

    def find_by_signals(self, signals: List[str]) -> List[str]:
        """根据信号查找经验包 ID"""
        index_path = self.index_dir / 'by-signal.jsonl'
        if not index_path.exists():
            return []

        matches: Set[str] = set()
        with open(index_path, 'r', encoding='utf-8') as f:
            for line in f:
                if not line.strip():
                    continue
                entry = json.loads(line)
                if entry['signal'] in signals:
                    matches.add(entry['package_id'])

        return list(matches)

    def _append_index(self, index_name: str, entry: dict) -> None:
        """追加索引条目"""
        index_path = self.index_dir / f'{index_name}.jsonl'
        with open(index_path, 'a', encoding='utf-8') as f:
            f.write(json.dumps(entry, ensure_ascii=False) + '\n')
```

## 16. 安全考虑

### 16.1 访问控制

**文件系统**：

- `brain/` 目录：755（Agent 可读）
- 单个文件：644（只读，防篡改）
- 不在 `secrets/` 黑名单中（允许 read 工具访问）

**HTTP API**：

- 默认只监听 `localhost`（不对外）
