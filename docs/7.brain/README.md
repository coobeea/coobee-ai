## 💡 核心设计理念

### 1. 双层 API 架构

- **Brain Worker API (42043)** → AI Agent 使用（纯 HTTP + Skill）
- **Gateway API (8765)** → 前端管理系统使用（`brain.*` 方法）
- ✅ 完全解耦，各司其职

### 2. 纯 HTTP，不注册工具

- ✅ Agent 通过 Skill 文档理解 API
- ✅ Agent 自己发送 HTTP 请求
- ✅ 标准化、易测试

### 3. 三元组知识结构

- **方案模板（Pattern）**: 解决策略
- **实践案例（Practice）**: 具体实现
- **演进记录（Evolution）**: 摸索过程

### 4. 内容寻址（SHA256）

- 每个资产的 ID 由其内容决定
- 自动去重 + 完整性校验

### 5. 本地文件系统

- 所有数据存文件（`.home/brain/`）
- 可查看、可备份、无需数据库
