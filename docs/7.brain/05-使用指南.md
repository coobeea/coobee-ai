# 智库（Brain）使用指南

> 本文档为智库系统的快速上手指南

---

## 1. 系统概述

智库（Brain）是 Coobee AI 的经验复用系统，提供：

- 📦 **经验包管理**: 存储和复用解决方案
- 🔍 **智能搜索**: 根据触发信号快速定位方案
- 🌐 **双层 API**: Agent 和 UI 分离访问
- 📊 **统计分析**: 经验包使用情况分析

### 2.2 搜索经验包

**方式 1: 使用 Python 脚本**（无需启动 Worker）

```bash
# 搜索与 TimeoutError 相关的方案
cd /Users/lifeng/git/git_agents/coobee-ai
python3 -c "
import sys
from pathlib import Path
sys.path.insert(0, 'workers/brain')

from brain.storage import FileSystemStore
from brain.indexer import IndexManager

storage_dir = '.home/brain'
indexer = IndexManager(storage_dir)
store = FileSystemStore(storage_dir)

# 搜索
package_ids = indexer.find_by_signals(['TimeoutError'])
print(f'Found {len(package_ids)} packages')

# 显示前 3 个
for pkg_id in package_ids[:3]:
    pkg = store.load_package(pkg_id)
    if pkg:
        print(f\"  - {pkg['pattern']['name']}: {pkg['practice']['summary']}\")
"
```

**方式 2: 启动 Brain Worker 使用 HTTP API**

```bash
# 1. 启动应用
pnpm dev

# 2. 在应用中启动 Brain Worker
# （通过 Settings → Workers → Brain → Start）

# 3. 使用 curl 搜索
curl -X POST http://localhost:42043/api/brain/search \
  -H 'Content-Type: application/json' \
  -d '{
    "message_id": "test_001",
    "timestamp": "2026-02-23T10:00:00Z",
    "payload": {
      "signals": ["TimeoutError"],
      "limit": 10
    }
  }'
```

## 4. Agent 使用示例

当 Agent 遇到问题时，可以查询智库：

```python
# Agent 代码示例
import json
import subprocess

def search_solution(error_type):
    """搜索解决方案"""
    payload = {
        "message_id": "agent_001",
        "timestamp": "2026-02-23T10:00:00Z",
        "payload": {
            "signals": [error_type],
            "status": "promoted",  # 只要已验证的方案
            "limit": 5
        }
    }

    # 写入临时文件
    with open('/tmp/brain_search.json', 'w') as f:
        json.dump(payload, f)

    # 调用 API
    result = subprocess.run([
        'curl', '-X', 'POST',
        'http://localhost:42043/api/brain/search',
        '-H', 'Content-Type: application/json',
        '-d', '@/tmp/brain_search.json',
        '-s'
    ], capture_output=True, text=True)

    response = json.loads(result.stdout)
    return response['data']['packages']

# 使用
packages = search_solution('TimeoutError')
for pkg in packages:
    print(f"方案: {pkg['pattern']['name']}")
    print(f"置信度: {pkg['practice']['confidence']}")
```

## 5. 前端管理（通过 Gateway）

前端可以通过 Gateway 管理智库：

```typescript
// 获取统计信息
const stats = await gateway.call('brain.stats', {});
console.log(`Total packages: ${stats.total}`);

// 列出经验包
const result = await gateway.call('brain.list', {
  limit: 20,
  offset: 0,
  category: 'repair'
});

// 获取完整经验包
const pkg = await gateway.call('brain.get', {
  packageId: 'pkg_a4762c7054f945f9'
});

// 删除经验包
await gateway.call('brain.delete', {
  packageId: 'pkg_a4762c7054f945f9'
});
```

## 8. 故障排除

### 问题 1: Brain Worker 未启动

**现象**: API 调用返回 "Connection refused"

**解决**:

```bash
# 通过前端启动 Worker
# Settings → Workers → Brain → Start

# 或者手动启动测试
cd workers/brain
USER_HOME=/Users/lifeng/git/git_agents/coobee-ai/.home \
python3 server.py --port 42043
```

### 问题 2: 搜索返回空结果

**现象**: 搜索不到任何经验包

**解决**:

```bash
# 检查数据是否存在
ls .home/brain/packages/ | wc -l  # 应该显示 100

# 检查索引
wc -l .home/brain/index/*.jsonl

# 如果索引损坏，重新构建
python3 -c "
from workers.brain.brain.storage import FileSystemStore
from workers.brain.brain.indexer import IndexManager

store = FileSystemStore('.home/brain')
indexer = IndexManager('.home/brain')

# 重建索引
for pkg_id in store.list_packages():
    pkg = store.load_package(pkg_id)
    if pkg:
        indexer.add_package(pkg)
"
```

### 问题 3: 映射表找不到

**现象**: `list_downloaded.py` 显示 "No packages"

**解决**:

```bash
# 检查映射表
cat .home/brain/sync/downloaded.json | head -50

# 如果不存在，重新同步
python3 skills/brain-sync/scripts/sync_offline.py --count 100 --force
```

## 9. 性能基准

基于 100 个经验包的测试数据：

| 操作           | 耗时    |
| -------------- | ------- |
| 搜索（按信号） | < 50ms  |
| 搜索（按类别） | < 30ms  |
| 加载完整包     | < 10ms  |
| 发布新包       | < 100ms |
| 统计信息       | < 50ms  |

存储占用：

- 100 个经验包 ≈ 500 KB
- 索引文件 ≈ 50 KB
- 总计 ≈ 550 KB
