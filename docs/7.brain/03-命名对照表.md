## 协议封装对比

### EvoMap（7 层 Envelope）

```json
{
  "protocol": "gep-a2a",
  "protocol_version": "1.0.0",
  "message_type": "publish",
  "message_id": "msg_xxx",
  "sender_id": "node_xxx",
  "timestamp": "2026-02-23T10:00:00Z",
  "payload": {
    /* 业务数据 */
  }
}
```

### Coobee Brain（3 层简化）

```json
{
  "message_id": "msg_xxx",
  "timestamp": "2026-02-23T10:00:00Z",
  "payload": {
    /* 业务数据 */
  }
}
```

**简化理由**:

- 我们是本地单机，不需要 protocol 协商
- 不需要 sender_id（文件系统自动记录）
- 不需要 message_type（通过 URL path 区分）

## 热门 Capsule 参考

从 EvoMap 热门资产学到的经验：

### 高质量资产的特征

1. **问题普遍** - 如 HTTP Retry（被复用 44 万次）
2. **效果显著** - 如 Agent Debug（减少 80% 人工）
3. **稳定性高** - confidence > 0.95, success_streak > 10
4. **独家能力** - "平台上尚无类似资产"

### 热门问题类型

1. 网络可靠性（HTTP retry, connection pool）
2. Agent 基础设施（内省调试, 跨会话记忆）
3. 生产环境（K8s OOM, 异常检测）

## 快速参考

### 发布经验包（我们的方式）

```bash
curl -X POST http://localhost:42043/api/brain/publish \
  -H "Content-Type: application/json" \
  -d '{
    "message_id": "msg_xxx",
    "timestamp": "2026-02-23T10:00:00Z",
    "payload": {
      "pattern": { "type": "Pattern", "name": "...", ... },
      "practice": { "type": "Practice", "name": "...", ... },
      "evolution": { "type": "Evolution", ... }
    }
  }'
```

### 搜索经验包（我们的方式）

```bash
curl -X POST http://localhost:42043/api/brain/search \
  -H "Content-Type: application/json" \
  -d '{
    "message_id": "msg_xxx",
    "timestamp": "2026-02-23T10:00:00Z",
    "payload": {
      "signals": ["TimeoutError"],
      "category": "repair",
      "limit": 10
    }
  }'
```
