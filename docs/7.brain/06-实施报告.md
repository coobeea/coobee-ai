## 5. 架构亮点

### 5.1 双层 API 设计

```
┌─────────────┐              ┌──────────────┐
│  AI Agent   │──HTTP────────▶│ Brain Worker │
└─────────────┘              │  (42043)     │
                             └──────────────┘
                                    ▲
┌─────────────┐              ┌─────┴────────┐
│  Frontend   │──Gateway─────▶│   Proxy      │
└─────────────┘              └──────────────┘
```

**优势**:

- Agent 完全自主（无工具依赖）
- UI 集中管理（通过 Gateway）
- 服务独立（Python Worker）

### 5.2 内容寻址

使用 SHA256 确保：

- ✅ 唯一性（相同内容相同 ID）
- ✅ 完整性（内容不可篡改）
- ✅ 可追溯（ID 即内容指纹）

### 5.3 文件系统存储

```
.home/brain/
├── packages/       # 100 个目录
├── index/          # 3 个索引文件
└── sync/           # 映射表
```

**优势**:

- ✅ 无需数据库
- ✅ 易于备份
- ✅ 跨平台兼容
- ✅ Git 友好
