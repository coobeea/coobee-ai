# 18. 实时分析模块（LiveInsight）

> **状态**: 需求分析 & 架构设计完成，待评审
> **创建时间**: 2026-03-06

## 概述

LiveInsight（实时洞察）是一个通用的"实时数据采集 + AI 分析"模块。核心流程：持续录音 → ASR 转写 → LLM 实时分析 → 结构化展示 → 快照回溯。

通过**分析模板**配置不同场景的分析维度和输出格式，适用于销售对话、会议纪要、面试评估、专业咨询等多种场景。

## 核心概念

- **AnalysisTemplate**（分析模板）：定义分析维度、提示词和刷新策略
- **InsightSession**（洞察会话）：一次完整的录音+分析过程
- **AnalysisSnapshot**（分析快照）：某一时刻的素材+结果，可回溯
- **DimensionType**（维度类型）：enum / score / text / list / boolean / tags / progress / comparison

## 实现路线

- **Phase 1**: 核心闭环 — 录音 → 转写 → 分析 → 展示（~8 天）
- **Phase 2**: 模板系统 + 历史回顾（~5.5 天）
- **Phase 3**: 增量分析 + 知识库集成（~4 天）
