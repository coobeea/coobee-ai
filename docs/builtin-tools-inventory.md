# 内置工具清单

系统内置 **12 个工具**，按功能分类如下。

**注意**：部分低频工具已迁移为 Skills + 脚本模式，以优化上下文占用：

- 可观测性工具 → `observability` Skill
- 配置管理工具 → `config-manager` Skill

---

## 📂 文件操作（3 个）

### 1. `read` - 读取文件

**用途**：读取文件内容，带行号显示

**风险等级**：🟢 低风险

**功能**：

- 读取文本文件内容
- 返回带行号的内容（`1|content`）
- 支持 offset/limit 分段读取大文件

**使用场景**：

- 查看代码
- 读取配置文件
- 检查日志

---

### 2. `write` - 写入文件

**用途**：写入或创建文件

**风险等级**：🟡 中风险

**功能**：

- 创建新文件（自动创建父目录）
- 覆盖已有文件
- 必须提供完整内容（不支持占位符）

**使用场景**：

- 创建新文件
- 完整替换文件内容
- 生成配置文件

**注意**：会完全覆盖已有文件，小心使用！

---

### 3. `edit` - 编辑文件

**用途**：精确替换文件中的文本

**风险等级**：🟡 中风险

**功能**：

- 查找并替换文本（必须精确匹配一次）
- 保留缩进和格式
- 提供足够上下文确保唯一匹配

**使用场景**：

- 修改代码片段
- 更新配置项
- 重构代码

**注意**：`oldText` 必须在文件中**精确出现一次**！

---

## ⚙️ 执行与进程（2 个）

### 4. `exec` - 执行命令

**用途**：执行 Shell 命令

**风险等级**：🔴 高风险

**功能**：

- **前台模式**（默认）：等待完成，返回输出
- **后台模式**（`background=true`）：立即返回 processId

**使用场景**：

- 运行构建命令
- 安装依赖
- 执行脚本
- 启动 dev server（后台模式）

**安全机制**：

- 黑名单拦截危险命令
- 审批策略（可配置）
- 工作目录限制

---

### 5. `process` - 管理后台进程

**用途**：管理 `exec(background=true)` 启动的进程

**风险等级**：🟡 中风险

**功能**：

- `list`：列出所有后台进程
- `read_output`：读取进程输出
- `send_input`：发送输入到进程
- `kill`：终止进程

**使用场景**：

- 管理 dev server
- 读取长时间运行任务的输出
- 交互式命令控制

---

## 🔍 搜索与发现（2 个）

### 6. `search` - 文件内容搜索

**用途**：在工作空间中搜索文本（类似 grep）

**风险等级**：🟢 低风险

**功能**：

- 支持正则表达式
- 返回匹配行及上下文
- 显示文件路径和行号

**使用场景**：

- 查找函数定义
- 搜索 TODO 注释
- 定位代码模式
- 查找配置项

---

### 7. `glob` - 文件名搜索

**用途**：按文件名模式查找文件

**风险等级**：🟢 低风险

**功能**：

- 支持 glob 模式（`*.ts`, `**/*.test.ts`）
- 返回文件路径、大小、修改时间

**使用场景**：

- 查找所有测试文件
- 列出某类型文件
- 查找配置文件
- 统计文件数量

---

## 🧠 记忆管理（1 个）

### 8. `memory` - 记忆管理

**用途**：管理持久化记忆文件

**风险等级**：🟢 低风险

**功能**：

- `list`：列出所有记忆文件
- `get`：读取记忆文件
- `save`：保存记忆文件
- `delete`：删除记忆文件

**记忆文件**：

- `MEMORY.md` - 主记忆文件
- `memory/*.md` - 分类记忆

**使用场景**：

- 保存重要信息
- 跨会话记忆
- 存储用户偏好
- 记录工作笔记

---

## 📚 发现（1 个）

### 9. `skill_list` - Skill 列表

**用途**：快速发现可用的 Skills

**风险等级**：🟢 低风险

**功能**：

- 列出所有 Skills
- 显示名称、描述、路径
- 只读，无参数

**使用场景**：

- 发现可用能力
- 查找相关 Skill
- 了解系统功能

**后续操作**：找到 Skill 后，用 `read` 工具读取其 `SKILL.md` 详细了解

---

## 🤝 Agent 协作（3 个）

### 10. `delegate_to_agent` - 委托任务

**用途**：委托子任务给专业 Agent

**风险等级**：🟡 中风险

**功能**：

- 在当前任务目录下创建子工作空间
- 传递 `taskId` 分组相关委托
- 自动共享执行经验

**使用场景**：

- 需要专家处理特定任务
- 并行执行多个子任务
- 分工协作

**使用流程**：

1. 先用 `manage_agent(list)` 检查是否有合适的 Agent
2. 委托任务给专业 Agent
3. 获取执行结果

---

### 11. `task_plan` - 任务计划管理

**用途**：创建和管理多步骤任务计划

**风险等级**：🟢 低风险

**功能**：

- `create`：创建任务计划（含步骤）
- `update_step`：更新步骤状态
- `get`：查看计划状态
- `list`：列出所有任务
- `complete`：完成任务

**持久化**：

- `tasks/{taskId}/plan.md` - 人类可读
- `tasks/{taskId}/status.json` - 机器可读

**使用场景**：

- 多步骤任务规划
- 进度跟踪
- 多 Agent 协作
- 任务报告

---

### 12. `todo_write` - TODO 管理

**用途**：管理当前会话的 TODO 列表

**风险等级**：🟢 低风险

**功能**：

- 创建 TODO 列表
- 更新 TODO 状态（pending/in_progress/completed/cancelled）
- `merge=false`：设置完整列表
- `merge=true`：更新指定项

**使用场景**：

- 规划多步骤任务
- 跟踪进度
- 向用户展示计划

**注意**：文件级持久化，会话间共享

## 🎯 工具选择指南

### 场景 1：文件操作

| 需求         | 推荐工具 | 理由           |
| ------------ | -------- | -------------- |
| 查看文件     | `read`   | 低风险，带行号 |
| 创建新文件   | `write`  | 直接创建       |
| 修改代码片段 | `edit`   | 精确替换       |
| 完全替换文件 | `write`  | 简单直接       |

### 场景 2：搜索

| 需求           | 推荐工具 | 理由           |
| -------------- | -------- | -------------- |
| 查找代码模式   | `search` | 支持正则       |
| 查找文件名     | `glob`   | 快速定位       |
| 查找函数定义   | `search` | 内容搜索       |
| 列出某类型文件 | `glob`   | 文件名模式匹配 |

### 场景 3：执行

| 需求            | 推荐工具       | 理由               |
| --------------- | -------------- | ------------------ |
| 运行构建命令    | `exec`（前台） | 等待完成           |
| 启动 dev server | `exec`（后台） | 长期运行           |
| 安装依赖        | `exec`（前台） | 等待完成           |
| 管理后台进程    | `process`      | 读输出/发输入/终止 |

### 场景 4：记忆和追踪

| 需求           | 推荐工具/Skill         | 理由        |
| -------------- | ---------------------- | ----------- |
| 保存重要信息   | `memory`               | 持久化      |
| 跟踪任务进度   | `todo_write`           | 会话级 TODO |
| 多步骤任务规划 | `task_plan`            | 结构化计划  |
| 查看对话历史   | `observability` Skill  | 时间线      |
| 调试 LLM 行为  | `observability` Skill  | 详细上下文  |
| 查看/修改配置  | `config-manager` Skill | 配置管理    |

## 🚨 使用注意事项

### 高风险工具

- **`exec`**：
  - ⚠️ 可执行任意命令
  - 📋 黑名单拦截危险命令
  - 🔐 审批策略可配置
  - 💡 优先使用专用工具（如 `read`/`write` 而非 `cat`/`echo`）

### 中风险工具

- **`write`**：完全覆盖文件，确认后再写
- **`edit`**：确保 `oldText` 精确匹配一次
- **`config_patch`**：配置立即生效，小心修改系统设置
- **`process`**：终止进程前确认无影响

### 文件操作最佳实践

1. **先读后写**：修改文件前先用 `read` 查看内容
2. **精确替换**：用 `edit` 时提供足够上下文
3. **完整内容**：用 `write` 时不要省略内容
4. **路径确认**：确认工作目录路径正确
