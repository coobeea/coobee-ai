# 审批策略修复报告

## 问题描述

用户在配置文件 `.home/config/coobee.json5` 中设置了：

```json5
security: {
  approvals: {
    exec: 'never'  // 永不审批
  }
}
```

但在实际执行中，当 Agent 调用 `exec` 工具时，仍然会弹出审批提示，要求用户确认。

## 根本原因

**审批判断逻辑未读取全局配置**

在 `ToolExecutionPipeline.ts` 的 Phase 1 审批判断中：

```typescript
// 原有代码（有问题）
if (def.name === 'exec' && params.command) {
  const policy = checkExecPolicy(params.command as string);

  if (policy.action === 'ask') {
    return await requestUserApproval(...); // 直接触发审批
  }
}
```

问题点：

1. `checkExecPolicy` 只检查**命令本身**的安全性（黑名单/白名单/未知）
2. **完全没有读取** `security.approvals.exec` 配置
3. 导致即使配置了 `exec: 'never'`，未知命令仍会触发审批

## 修复方案

在 Phase 1 审批判断前，先读取并应用全局 `execApproval` 配置：

```typescript
// 修复后的代码
if (def.name === 'exec' && params.command) {
  // 1. 读取全局审批策略
  let execApproval: 'auto' | 'always' | 'never' = 'auto';
  try {
    const { configStoreInstance } = await import('../../../common/config/ConfigStore');
    if (configStoreInstance) {
      const security = configStoreInstance.get('security');
      execApproval = security?.approvals?.exec ?? 'auto';
    }
  } catch {
    // 降级到默认值
  }

  // 2. 检查命令安全性
  const policy = checkExecPolicy(params.command as string);

  // 2.1 黑名单始终拒绝（不受配置影响）
  if (policy.action === 'deny') {
    return { blocked: true, ... };
  }

  // 3. 根据全局策略和命令安全性决定
  if (execApproval === 'never') {
    // 跳过审批，直接执行
  } else if (execApproval === 'always') {
    // 强制审批（即使白名单命令）
    return await requestUserApproval(...);
  } else {
    // execApproval = 'auto'
    if (policy.action === 'ask') {
      // 未知命令需要审批
      return await requestUserApproval(...);
    }
    // policy.action === 'allow' → 白名单自动放行
  }
}
```

## 三种策略模式

| 配置值        | 黑名单命令 | 白名单命令  | 未知命令    |
| ------------- | ---------- | ----------- | ----------- |
| `never`       | ❌ 拒绝    | ✅ 直接执行 | ✅ 直接执行 |
| `auto` (默认) | ❌ 拒绝    | ✅ 直接执行 | ⏸️ 触发审批 |
| `always`      | ❌ 拒绝    | ⏸️ 触发审批 | ⏸️ 触发审批 |

注意：

- **黑名单命令**（如 `rm -rf /`, `sudo`, `curl | sh`）始终被拒绝，不受配置影响
- **白名单命令**（如 `ls`, `git`, `npm`）在 `auto` 和 `never` 模式下自动放行
- **未知命令**（如 `docker`, 自定义脚本）只在 `never` 模式下跳过审批

## 如何验证修复

1. 确认配置文件中 `security.approvals.exec = 'never'`
2. 重启应用（让新代码生效）
3. 发送消息让 Agent 执行命令（如 `请执行 docker ps`）
4. 验证**不弹出审批提示**，命令直接执行
