# Coobee AI

An Electron application with Vue and TypeScript

## ✨ 技术栈

- **框架**: Electron + Vue 3 + TypeScript
- **构建工具**: Electron Vite
- **样式**: Tailwind CSS 4
- **图标**: unplugin-icons + @iconify/tailwind4
- **状态管理**: Pinia
- **路由**: Vue Router
- **编辑器**: Monaco Editor

## 📦 项目特性

- ✅ **三种图标使用方式** - 组件、自动导入、CSS 类，覆盖所有使用场景
- ✅ **离线图标** - 200,000+ 图标，完全离线打包
- ✅ **类型安全** - 完整的 TypeScript 支持
- ✅ **热更新** - 快速开发体验
- ✅ **现代化 UI** - 基于 Tailwind CSS 4

## Project Setup

### Install

```bash
$ pnpm install
```

### Development

```bash
$ pnpm dev
```

### Build

```bash
# For windows
$ pnpm build:win

# For macOS
$ pnpm build:mac

# For Linux
$ pnpm build:linux
```
