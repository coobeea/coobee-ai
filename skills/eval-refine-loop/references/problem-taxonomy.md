# 问题分类体系

## 5 种问题类型详解

### 1. 遗漏（Missing）

**定义**：维度在 LLM 输出中完全未被提及或分析。

**检测方式**：在输出中搜索与该维度相关的关键词、概念、判断，均未找到。

**典型场景**：

- 合同审查输出中完全未提及"增值税专项风险"维度
- 学习评估中遗漏了"知识迁移能力"维度

**优化指令模板**：

```
【补充分析】
维度：{维度名}
维度定义：{来自 dimension-analysis.md 的描述}
评估标准：{该维度的判定标准}
要求：请针对上述维度进行完整分析，输出必须覆盖该维度的所有子检查项。
```

**严重程度评定**：

- 高权重维度遗漏 → 高
- 低权重维度遗漏 → 中

---

### 2. 错误（Incorrect）

**定义**：维度被分析了，但结论与事实或评估标准不符。

**检测方式**：将输出中的判定结论与评估标准逐条比对，发现矛盾。

**典型场景**：

- 合同明确约定 13% 税率，输出判定为"税率适用正确"但实际业务应适用 6%
- 合同无违约责任条款，输出判定为"条款完整"

**优化指令模板**：

```
【纠正错误】
维度：{维度名}
你的判断：{LLM 输出的结论}
正确分析：{指出错误原因及正确方向}
评估标准：{该维度的判定标准}
要求：请基于评估标准重新分析该维度，修正上述错误。
```

**严重程度评定**：

- 核心结论错误（影响最终判定） → 高
- 非核心细节错误 → 中

---

### 3. 不足（Insufficient）

**定义**：维度有分析但深度不够，未达到评估标准要求的粒度。

**检测方式**：对照评估标准中的子检查项/判定标准，输出仅覆盖部分内容。

**典型场景**：

- "税务条款规范性"维度只说了"基本规范"，但未逐项检查 6 个子检查项
- "权利义务对等性"只给了结论没有具体分析各子项

**优化指令模板**：

```
【深化分析】
维度：{维度名}
当前分析：{LLM 输出的现有内容概述}
缺少内容：{具体缺失的子项/要素列表}
评估标准：{该维度的完整判定标准}
要求：请补充上述缺失内容，分析深度须达到评估标准的要求。
```

**严重程度评定**：

- 缺少关键子项（影响维度判定） → 中
- 缺少次要细节 → 低

---

### 4. 偏离（Deviated）

**定义**：内容存在但与维度定义衡量的目标不匹配。

**检测方式**：输出中有相关内容，但分析角度或关注点与维度定义不一致。

**典型场景**：

- "权利义务对等性"维度下讨论了合同付款流程的操作细节，而非双方权利义务的平衡
- "核心条款完整性"维度下分析了条款的法律效力，而非条款是否齐全

**优化指令模板**：

```
【校正方向】
维度：{维度名}
维度定义：{来自 dimension-analysis.md 的定义}
你的分析方向：{LLM 输出中偏离的内容概述}
正确方向：{该维度真正衡量的内容}
要求：请重新对齐维度定义，按正确方向重新分析。
```

**严重程度评定**：

- 方向完全偏离（内容与维度无关联） → 中
- 方向部分偏离（有关联但侧重点错） → 低

---

### 5. 冗余（Redundant）

**定义**：输出中包含与任何维度定义都无关的内容。

**检测方式**：将输出内容逐段与所有维度定义比对，找出无法归属于任何维度的段落。

**典型场景**：

- 合同审查输出中大段描述了行业发展趋势
- 输出中重复分析了已在其他维度覆盖的内容

**优化指令模板**：

```
【精简内容】
以下内容与维度体系中的任何维度均不相关，请移除或精简：
- {冗余内容1的概述}
- {冗余内容2的概述}
要求：保留与维度体系相关的所有分析，仅移除无关内容。
```

**严重程度评定**：

- 冗余内容大量占据篇幅（>30%） → 中
- 少量冗余 → 低

---

## 问题类型与优化策略的关系

| 问题类型 | 策略A（针对性修正）     | 策略B（引导式重生成）    |
| -------- | ----------------------- | ------------------------ |
| 遗漏     | 生成补充指令            | 将遗漏维度加入硬约束清单 |
| 错误     | 生成纠正指令 + 正确参考 | 在失败摘要中标注错误模式 |
| 不足     | 生成深化指令 + 缺失清单 | 在约束中明确深度要求     |
| 偏离     | 生成校正指令 + 维度定义 | 在约束中强化维度定义     |
| 冗余     | 生成精简指令            | 在约束中明确输出边界     |

## 多问题优先级排序

当存在多个问题时，按以下优先级处理：

1. **错误**（高优先）— 错误结论比没有结论更危险
2. **遗漏**（高优先）— 关键维度缺失影响整体可用性
3. **偏离**（中优先）— 方向错了越分析越偏
4. **不足**（中优先）— 有基础但需要深化
5. **冗余**（低优先）— 不影响正确性，只影响简洁度
