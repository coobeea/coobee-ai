# 发票审查 · 批次评估 · 评估优化经验

**创建日期**：2026-02-16
**更新日期**：2026-02-16
**累计闭环次数**：1

## 领域概要

发票审查 Skill 对发票与会计凭证进行 6 维度审查（形式合规、业务匹配、税务计算、凭证匹配、增值税风险、内控合规）。batch-10 为多维度复合问题批次，每条记录跨多个维度有问题，编号 100 为全维度问题。

## LLM 弱点模式

| 维度           | 常见问题类型 | 出现频率 | 说明                                                                                 |
| -------------- | ------------ | -------- | ------------------------------------------------------------------------------------ |
| 凭证匹配性     | 错误         | 1/1 次   | 编号 093：凭证贷方金额表述错误（50000 vs 50500），可能与「正确价税合计」混淆导致笔误 |
| 税务计算准确性 | 错误         | 1/1 次   | 同上，与凭证匹配性联动，税额/价税合计分析正确但凭证金额表述出错                      |

## 策略有效性

| 场景         | 推荐策略 | 原因                                   |
| ------------ | -------- | -------------------------------------- |
| 单处事实错误 | 策略 A   | 问题少，针对性修正即可，1 轮修正即达标 |

## 推荐参数

| 参数     | 推荐值 | 默认值 | 调整原因 |
| -------- | ------ | ------ | -------- |
| 最大轮次 | 3      | 3      | 保持默认 |

## 问题分布

| 问题类型 | 占比 | 说明                           |
| -------- | ---- | ------------------------------ |
| 错误     | 100% | 凭证金额数字表述与原始数据不符 |

## 关键经验

- **有效做法**：逐条对照原始数据（test-data）核验报告中的金额、发票号等关键数字
- **避坑经验**：凭证匹配性分析时，区分「凭证实际金额」与「正确金额」，避免将两者混淆
- **改进建议**：发票审查 Skill 可在输出前增加「金额交叉校验」步骤，对凭证贷方、进项税额等与发票逐项核对
