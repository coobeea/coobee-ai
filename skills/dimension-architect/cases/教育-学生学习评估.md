# 教育 · 学生学习评估

**创建日期**：2026-02-15
**来源**：deep-interactive-learning Skill 实战经验

## 需求概要

为小学至初中学生建立学习效果评估体系，通过口述复述和习题实操两种方式采集数据，实现知识点掌握度和能力成长的量化追踪。

## 领域标签

教育, K12, 学习评估, 知识点掌握, 能力成长, 口述复述, 习题批改

## 维度方案（可直接复用）

### 知识点掌握维度（4级）

| 维度            | 类型   | 取值                             | 权重 | 适用说明                                                 |
| --------------- | ------ | -------------------------------- | ---- | -------------------------------------------------------- |
| 知识点理论掌握  | 等级型 | 优秀/良好/薄弱                   | 40%  | 口述复述场景，通过4维度映射（✅→优秀, ⚠️→良好, ❌→薄弱） |
| 知识点实操掌握  | 等级型 | 优秀/良好/薄弱                   | 40%  | 习题实操场景，通过答题正确率映射                         |
| 理论-实操一致性 | 选项型 | [一致/理论强实操弱/理论弱实操强] | 10%  | 交叉诊断维度                                             |
| 知识迁移能力    | 等级型 | 优秀/良好/一般/薄弱              | 10%  | 需多次学习后才能评估                                     |

### 能力成长维度（通用）

| 维度         | 类型   | 取值                | 适用说明         |
| ------------ | ------ | ------------------- | ---------------- |
| 框架把握     | 等级型 | 优秀/良好/一般/薄弱 | 能否抓住整体结构 |
| 关键信息捕捉 | 等级型 | 优秀/良好/一般/薄弱 | 是否抓住重点     |
| 细节记忆力   | 等级型 | 优秀/良好/一般/薄弱 | 事实细节准确性   |
| 表达流畅度   | 等级型 | 优秀/良好/一般/薄弱 | 口述场景专用     |
| 审题准确度   | 等级型 | 优秀/良好/一般/薄弱 | 习题场景专用     |
| 自我纠错     | 等级型 | 优秀/良好/一般/薄弱 | 多轮交互后评估   |

### 优点/改进标签体系

| 类型 | 标签集合                                                                             |
| ---- | ------------------------------------------------------------------------------------ |
| 优点 | 框架意识强, 概括能力好, 表达流畅, 进步明显, 举一反三, 审题仔细, 计算准确, 自我纠错强 |
| 改进 | 细节遗漏, 记忆偏差, 覆盖不全, 表述模糊, 逻辑跳跃, 审题不清, 计算粗心, 方法欠缺       |

## 关键经验

- **有效做法**：每次交互后同时输出"优点+改进点"，用结构化标签落地，积累3次以上就能看出稳定模式
- **有效做法**：口述复述中的错误也要记入错题本（不只是习题），按"概念错误/记忆错误/表述错误/遗漏"分类
- **注意事项**：查询操作（如"看看我的情况"）不应触发文件写入，只读取已有数据返回
- **注意事项**：维度不要一次设计太多，先从核心3-5个开始，随数据积累逐步扩展
- **用户特别认可的点**：优点+改进点的落地机制（growth-track），以及"稳定标签晋升"到 profile 的规则

## 可复用模式

此维度方案可套用于以下类似场景：

- 任何"知识掌握度评估"场景（培训效果评估、员工技能认证等）
- 需要"理论+实操"双通道评估的场景
- 需要长期追踪成长轨迹的场景
