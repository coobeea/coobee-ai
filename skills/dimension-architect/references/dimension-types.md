# 维度类型详解

## 5 种维度类型

### 1. 数值型（Numeric）

用精确数字衡量，支持数学运算。

| 属性 | 说明      | 示例             |
| ---- | --------- | ---------------- |
| 取值 | 具体数字  | 85分、3.5秒、92% |
| 范围 | min - max | 0-100分          |
| 精度 | 小数位数  | 整数 / 1位小数   |
| 单位 | 计量单位  | 分、秒、%、元    |

**适用场景**：考试分数、响应时间、完成率、成本预算

**示例**：

```
维度：考试得分率
类型：数值型
取值范围：0% - 100%
基线：65%
目标：≥85%
```

### 2. 等级型（Level）

用有序等级衡量，等级间有明确的高低关系。

| 属性     | 说明           | 示例                          |
| -------- | -------------- | ----------------------------- |
| 等级数   | 一般 3-5 级    | 4级、5级                      |
| 等级名   | 每级名称       | 优秀/良好/一般/薄弱           |
| 判定标准 | 每级的具体含义 | "优秀 = 能独立完成并举一反三" |

**适用场景**：能力评估、掌握程度、满意度

**常用等级模板**：

- 4级：优秀 / 良好 / 一般 / 薄弱
- 5级：卓越 / 优秀 / 良好 / 及格 / 不及格
- 3级：达标 / 接近 / 未达标

**示例**：

```
维度：框架把握能力
类型：等级型
取值：优秀 / 良好 / 一般 / 薄弱
判定标准：
  优秀 = 能完整复述结构，并解释每部分的作用
  良好 = 能说出主要结构，有少量遗漏
  一般 = 能说出部分结构，但不完整
  薄弱 = 无法描述文章结构
```

### 3. 布尔型（Boolean）

是/否二值判断。

| 属性 | 说明         | 示例                      |
| ---- | ------------ | ------------------------- |
| 取值 | 两个互斥选项 | 是/否、通过/未通过、有/无 |

**适用场景**：合规检查、功能验收、前置条件判断

**示例**：

```
维度：是否包含错别字
类型：布尔型
取值：有 / 无
目标：无
```

### 4. 范围型（Range）

在一个连续区间内取值，关注是否落在目标范围内。

| 属性     | 说明         | 示例  |
| -------- | ------------ | ----- |
| 下界     | 最低可接受值 | ≥60   |
| 上界     | 最高可接受值 | ≤100  |
| 理想区间 | 最佳范围     | 80-95 |

**适用场景**：性能指标（响应时间在 x-y ms）、预算控制、温度范围

**示例**：

```
维度：页面加载时间
类型：范围型
理想区间：0.5s - 1.5s
可接受上界：3s
超标：>3s
```

### 5. 选项型（Options）

从预定义的选项中选择，选项间无必然的高低关系。

| 属性     | 说明         | 示例                                     |
| -------- | ------------ | ---------------------------------------- |
| 选项列表 | 可选值集合   | [概念错误, 计算错误, 审题错误, 方法错误] |
| 多选     | 是否允许多选 | 是/否                                    |

**适用场景**：错误类型分类、风格分类、策略选择

**示例**：

```
维度：错误类型
类型：选项型（多选）
取值：[概念错误, 计算错误, 审题错误, 方法错误, 表述错误]
```

## 类型选择指南

```
需要精确数字？ → 数值型
需要分高低等级？ → 等级型
只需要是/否？ → 布尔型
关注是否在范围内？ → 范围型
需要分类但无高低？ → 选项型
```

## 复合维度

一个大维度下包含多个子维度（不同类型），形成层级结构：

```
大维度：语言表达能力
├── 子维度1：词汇丰富度（等级型：优秀/良好/一般/薄弱）
├── 子维度2：语法正确率（数值型：0-100%）
├── 子维度3：是否有逻辑跳跃（布尔型：有/无）
└── 子维度4：表达风格（选项型：[简洁/详细/口语化/书面化]）
```
