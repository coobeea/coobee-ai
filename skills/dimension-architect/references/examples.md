## 1. 教育-学生学习评估

**意图**：评估学生对某课程的掌握程度
**目标**：知识点掌握率≥80%，能力维度均达"良好"以上

| 维度         | 类型   | 取值                | 权重 |
| ------------ | ------ | ------------------- | ---- |
| 知识点掌握率 | 数值型 | 0-100%              | 40%  |
| 框架把握能力 | 等级型 | 优秀/良好/一般/薄弱 | 20%  |
| 细节记忆力   | 等级型 | 优秀/良好/一般/薄弱 | 15%  |
| 表达流畅度   | 等级型 | 优秀/良好/一般/薄弱 | 10%  |
| 知识迁移能力 | 等级型 | 优秀/良好/一般/薄弱 | 15%  |

## 2. 产品-用户体验评估

**意图**：评估产品的用户体验质量
**目标**：NPS≥50，核心流程完成率≥90%

| 维度         | 类型   | 取值                 | 权重 |
| ------------ | ------ | -------------------- | ---- |
| 任务完成率   | 数值型 | 0-100%               | 25%  |
| 操作步骤数   | 范围型 | 理想≤3步，可接受≤5步 | 15%  |
| 页面加载时间 | 范围型 | 理想<1s，可接受<3s   | 15%  |
| 视觉一致性   | 等级型 | 优秀/良好/一般/差    | 15%  |
| 错误处理     | 等级型 | 优秀/良好/一般/差    | 15%  |
| 无障碍合规   | 布尔型 | 达标/未达标          | 15%  |

## 3. 写作-文章质量评审

**意图**：评估文章的整体质量
**目标**：读者能理解核心观点并认同论证

| 维度        | 类型   | 取值                | 权重 |
| ----------- | ------ | ------------------- | ---- |
| 逻辑结构    | 等级型 | 优秀/良好/一般/薄弱 | 25%  |
| 论证力度    | 等级型 | 优秀/良好/一般/薄弱 | 25%  |
| 语言表达    | 等级型 | 优秀/良好/一般/薄弱 | 20%  |
| 数据支撑    | 等级型 | 充分/部分/缺乏      | 15%  |
| 格式规范    | 布尔型 | 达标/未达标         | 5%   |
| 错别字/语病 | 数值型 | 0-N处               | 10%  |

## 4. 招聘-候选人评估

**意图**：评估候选人与岗位的匹配度
**目标**：综合匹配度≥80%

| 维度         | 类型   | 取值                       | 权重 |
| ------------ | ------ | -------------------------- | ---- |
| 技术能力     | 等级型 | 卓越/优秀/良好/及格/不及格 | 30%  |
| 项目经验匹配 | 数值型 | 0-100%                     | 20%  |
| 沟通协作     | 等级型 | 卓越/优秀/良好/及格/不及格 | 20%  |
| 学习潜力     | 等级型 | 高/中/低                   | 15%  |
| 文化契合度   | 等级型 | 高/中/低                   | 15%  |

## 5. 项目管理-项目健康度

**意图**：评估项目当前的健康状态
**目标**：所有维度均为"绿灯"

| 维度     | 类型   | 取值                | 权重 |
| -------- | ------ | ------------------- | ---- |
| 进度偏差 | 范围型 | 理想±5%，可接受±15% | 25%  |
| 预算偏差 | 范围型 | 理想±5%，可接受±10% | 25%  |
| 质量指标 | 数值型 | bug数/千行代码      | 20%  |
| 团队士气 | 等级型 | 高/中/低            | 15%  |
| 风险等级 | 选项型 | [红/黄/绿]          | 15%  |
