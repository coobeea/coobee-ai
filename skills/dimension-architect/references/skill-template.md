# Skill 生成模板

dimension-architect 完成维度设计后，Phase 5 按此模板生成领域 Skill。

## 生成的 Skill 目录结构

```
{领域名称}/
├── SKILL.md                    # 工作流（按下方模板生成）
├── references/
│   └── dimensions.md           # 维度定义 + 评估标准（原 dimension-analysis.md 的内容）
├── evaluations/                # 审查/评估记录
└── eval-reports/               # eval-refine-loop 报告
```

同时注册到 `.cursor/skills/{领域名称}/SKILL.md`。

## SKILL.md 生成模板

```markdown
---
name: { 英文标识，如 contract-review }
description: '{领域}{场景}工具。按照{N}维度体系系统{动作}，{核心价值描述}。Use when: {触发场景列表}. Triggers on: {触发关键词列表}.'
---

# {领域名称}

## 核心职责

输入{输入物}，按 {N} 维度体系系统{动作}，输出{输出物}。

## 维度体系

本 Skill 基于 `dimension-architect` 设计的 {N} 维度体系，详见 [dimensions.md](references/dimensions.md)。

{维度总览图，用缩进表示层级}

## {动作}流程

{根据维度的层级结构和审查顺序，生成 Step 1 ~ Step N+1 的工作流}

### Step 1: 基本信息提取

{从输入物中提取基本信息}

### Step 2 ~ Step N: 逐层/逐维度处理

{每个步骤对应一个维度或一层维度}
{每步包含：子检查项列表、判定规则、快速决策逻辑}

### Step N+1: 综合评定

{汇总所有维度结果，给出综合判定}

综合评定规则：
| 综合等级 | 判定规则 | 结论 |
|----------|----------|------|
| 高风险/严重 | 任一维度为最差等级 | {对应结论} |
| 中等 | 多个维度为中等问题 | {对应结论} |
| 低/轻微 | 仅少量轻微问题 | {对应结论} |
| 通过/达标 | 所有维度达标 | {对应结论} |

### Step N+2: 输出报告

{结构化报告模板}

## 数据落地

评估记录保存到 `evaluations/YYYY-MM-DD-{主题}.md`

## 与 eval-refine-loop 协作

eval-refine-loop 读取 `references/dimensions.md` 作为评估基准，对本 Skill 的输出进行质量闭环。
```

## 生成时的填充规则

| 模板占位符   | 数据来源                                               |
| ------------ | ------------------------------------------------------ |
| {领域名称}   | Phase 1 的所属领域                                     |
| {英文标识}   | 领域名称的英文翻译，kebab-case                         |
| {N}          | Phase 3 的维度数量                                     |
| {动作}       | Phase 1 的真实意图中的核心动作（如"审查""评估""分析"） |
| {输入物}     | Phase 1 的约束条件中的输入（如"合同文本""学生作业"）   |
| {输出物}     | Phase 2 的关键结果中的输出（如"审查报告""评估报告"）   |
| {维度总览图} | Phase 3 的维度层级结构                                 |
| 工作流步骤   | 根据维度的审查顺序自动生成                             |
| 综合评定规则 | 根据各维度的取值类型和权重推导                         |

## dimensions.md 的内容

直接使用原 dimension-analysis.md 的完整内容，包括：

- 意图分析
- 目标体系
- 维度定义（总览 + 各维度详细定义）
- 评估标准
- 数据采集方式
