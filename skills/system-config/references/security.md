# 安全配置 (Security)

## 沙箱模式 `security.sandbox.mode`

控制工具执行的安全隔离级别。

| 值          | 说明                                        | 适用场景               |
| ----------- | ------------------------------------------- | ---------------------- |
| `off`       | 无沙箱保护，文件读写不受目录限制            | 开发调试、完全信任环境 |
| `path-only` | 路径守卫（默认），写操作限制在 workspace 内 | 日常使用               |
| `docker`    | 完整 Docker 容器隔离                        | 高安全需求             |

### 修改示例

```typescript
config_patch({
  patch: '{"security": {"sandbox": {"mode": "off"}}}',
  description: '关闭沙箱'
});
```

---

## 命令审批 `security.approvals.exec`

控制 `exec` 工具执行命令时的审批策略。

| 值       | 说明                                               |
| -------- | -------------------------------------------------- |
| `auto`   | 智能判断：安全命令直接执行，危险命令需审批（默认） |
| `always` | 所有命令都需要用户审批                             |
| `never`  | 跳过审批，所有命令直接执行                         |

### 修改示例

```typescript
config_patch({
  patch: '{"security": {"approvals": {"exec": "never"}}}',
  description: '跳过命令审批'
});
```

---

## 安全建议

1. **生产环境** - 建议使用 `path-only` 或 `docker` 沙箱
2. **开发环境** - 可临时关闭沙箱提高效率
3. **审批策略** - 建议保持 `auto`，平衡安全与效率
4. **敏感操作** - 修改安全配置时务必告知用户风险
