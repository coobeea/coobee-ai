# 通用经验管理系统 使用指南

> 版本：v1.0
> 创建时间：2026-02-24

---

## 🎯 一句话说明

**通用的、自动化的、三层结构的问题和解决方案管理系统。**

- **三层结构**：问题（第1层）→ 解决方案（第2层：怎么做）→ 推导过程（第3层：为什么）
- **自动化**：执行前自动查询、执行中自动切换、执行后自动沉淀
- **通用化**：任何Skill都可接入使用

---

## 🏗️ 核心设计

### 三层结构

```
问题（第1层）
  ├─ 问题描述
  ├─ 解决思路（概要）
  └─ 方案索引
      ├─ 方案1（第2层 + 第3层）
      │   ├─ 具体实现（代码/步骤）
      │   └─ 推导过程（为什么）
      ├─ 方案2
      └─ 方案3...
```

---

## 🤖 三个自动化时机

### ① 执行前：自动查询

```
用户输入
  ↓
【自动】在经验库中搜索类似问题（<1秒）
  ├─ 找到 → "🔍 找到相关经验：P001（推荐S001，成功率95%）"
  │          "[使用/跳过]"
  └─ 未找到 → 【静默】继续正常流程
```

### ② 执行中：自动切换

```
执行 S001
  ↓
⚠️ 遇到困难
  ↓
【自动】查询备选方案
  ├─ 找到 S002 → "🔄 自动尝试备选方案：S002"
  └─ 未找到 → 【记录】新的失败模式
```

### ③ 执行后：自动沉淀

```
执行完成
  ↓
【自动】判断是否需要沉淀
  ├─ 遇到困难 ✅
  ├─ 场景复杂 ✅
  ├─ 新方法 ✅
  └─ 耗时长 ✅
  ↓
【自动】提取关键信息 → 创建文件 → 更新索引
  ↓
"✅ 经验已自动保存：P00X/S00X"
```

## 🚀 快速开始

### 作为用户：无需操作

系统已完全自动化，你只会看到：

- `🔍 找到相关经验`（执行前）
- `🔄 自动尝试备选方案`（执行中）
- `✅ 经验已自动保存`（执行后）

### 作为开发者：集成到新Skill

在业务Skill的 `SKILL.md` 核心流程中增加：

```markdown
**🤖 已集成经验管理系统**（自动执行，用户无感知）：

1. 执行前：自动查询经验库中的类似问题，找到则推荐已验证方案
2. 执行中：遇到困难时自动查询备选方案
3. 执行后：满足条件（复杂/困难/新方法）自动沉淀经验

详见：[experience-manager](../experience-manager/SKILL.md)
```

### 手动创建问题和方案

**Step 1**：复制模板

```bash
mkdir -p problems/P00X-xxx/solutions
cp templates/problem-template.md problems/P00X-xxx/problem.md
cp templates/solution-template.md problems/P00X-xxx/solutions/S001-xxx.md
```

**Step 2**：填充内容（按模板各section填写）

**Step 3**：更新 `problems/_index.md` 和统计文件

## 🔍 如何查询经验库？

**自动查询**（推荐）：使用集成了经验管理的任何skill时，系统会自动查询并提示。

**手动查询**：

```
Read: experience-manager/problems/_index.md
Grep: "#关键词" in experience-manager/problems/
```

## 💡 设计理念

| 层次          | 回答的问题     | 内容                         |
| ------------- | -------------- | ---------------------------- |
| 第1层（What） | 问题是什么？   | 业务场景、核心困惑、方案索引 |
| 第2层（How）  | 怎么做？       | 具体步骤、代码、配置         |
| 第3层（Why）  | 为什么这样做？ | 决策分析、方案对比、容错机制 |
